## conflict_design（冲突设计与升级规则）

目标：让每一场的冲突清楚、可见、可升级、可兑现；避免冲突停留在口头争吵或模糊对立。

### 1) 短剧冲突五大类型

**① 关系冲突**
- 核心：两个角色的欲望或目标直接碰撞
- 常见形式：背叛、争夺、嫉妒、权力不对等、感情拉扯
- 兑现方式：当场撕破脸、冷战、秘密曝光、主动退出关系

**② 身份冲突**
- 核心：真实身份与表面身份之间的错位与压力
- 常见形式：真假千金、卧底、隐瞒、身份落差、马甲被拆
- 兑现方式：被发现、被逼表态、被人拿来要挟、当众曝光

**③ 资源冲突**
- 核心：角色争夺同一个有限资源（权力、金钱、机会、情感）
- 常见形式：争继承、争职位、争人、抢证据、争时间
- 兑现方式：有人拿到/有人失去、资源被第三方截走、代价翻倍

**④ 秘密冲突**
- 核心：一方知道另一方不知道的事，形成信息差张力
- 常见形式：隐瞒真相、保护谎言、假装不知道、刻意误导
- 兑现方式：秘密被偷听、证据被发现、逼问失口、第三者告知

**⑤ 规则冲突（系统/规矩/协议）**
- 核心：角色被规则逼入两难，无论怎么选都有代价
- 常见形式：系统惩罚、合约期限、家族规矩、赌约到期、道德边界
- 兑现方式：规则触发后果、有人违规被惩罚、规则被人利用反制

---

### 2) 冲突升级三步法

**第一步：建立落差（压制场）**
- 主角处于明显弱势：被羞辱、被误解、被夺走、被当众否定
- 落差要可见：不靠旁白说"他很惨"，要让观众自己看到结果

**第二步：逼出代价（抉择场）**
- 冲突升级，主角被迫做选择
- 每次选择都带代价：选 A 失去什么，选 B 又触发什么
- 不允许主角无代价地化险为夷

**第三步：兑现反转（爆点场）**
- 冲突正式兑现：赢了、输了、或者变成更大的局
- 爆点必须被人看见（围观感）
- 兑现后不能重置，必须带出新状态或新压力

---

### 3) 冲突节奏控制

- 同一集内不要连续三场都使用同一类型冲突
- 每 2-3 场设一次"冲突升级"，让局势变得更复杂
- 每集至少有一次"信息不对称冲突"（一方知道、一方不知道）
- 冲突兑现后必须留尾巴：有人心怀不满、有代价未了结、有新危机引入

### 3.5) 头部样本常用推进器

- **关系变化优先**：冲突不只为了吵起来，而是为了让两个人的站位、边界、信任或依赖发生变化。
- **信息差必须流动**：秘密冲突最好写成“生成信息差 / 半揭露 / 回收后抛更大问题”的链条，不能只拖不解。
- **权力归属要可见**：谁压谁、谁翻盘、谁获得话语权、谁失去支持，要在动作、证据、围观或规则后果上被看见。
- **误会和错认是高效冲突引擎**：适合拖住关系、挂住钩子，但不能无限空转；同一误会拖过 3 集必须升级或回收。
- **承诺链要挂住冲突尾巴**：一句没说完的话、一次被打断的婚礼、一次尚未兑现的报复，都可以成为下一集的冲突接口。

---

### 4) 冲突与爽点/虐点/悬疑点/甜点绑定

- **爽点** = 主角当场赢得冲突，且被人看见
- **虐点** = 主角在冲突中失去重要的东西，代价清晰可感
- **悬疑点** = 冲突未被完全兑现，下一集必须继续追
- **甜点**（女频）= 冲突中两人关系温度发生了变化，偏爱/误会/拉扯都算

每场冲突至少命中以上一项，最好两项叠加。

---

### 5) 常见冲突设计错误与修正

| 错误 | 修正方向 |
|---|---|
| 只靠台词吵架，不落动作 | 让争执落到抢东西、拦人、曝光、签字、亮证据等可拍动作 |
| 冲突兑现后立刻重置 | 赢了要带出新敌意，输了要带出新的求生欲 |
| 同类型冲突无限重复 | 同一秘密/同一误会不能拖过3集，必须升级或切换类型 |
| 冲突只有主角知道 | 关键冲突必须让围观角色知情，爽点/虐点才有传播感 |
| 用旁白解释冲突 | 用行动替代解释：让结果出现，让观众自己得出结论 |
| 只有事件推进，没有关系/权力变化 | 让冲突兑现后明确写出谁更近、谁更远、谁更占上风 |
| 揭秘了，但没产生后果 | 真相一旦揭露，必须带出站队变化、关系破裂、资源变化或规则惩罚 |
