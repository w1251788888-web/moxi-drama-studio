## satisfaction_taxonomy（爽点分类与使用原则）

来源：`45种爽点.docx` 与 `漫剧制作人员须知.docx`。完整爽点卡进入 RAG；本文件只保留底层原则。

### 1) 七大爽点武器库

| 类别 | 典型爽点 | 使用方式 |
|---|---|---|
| 实力碾压类 | 扮猪吃虎、能力碾压、降维打击、幕后黑手、信息差 | 先让对手误判，再用可见结果兑现 |
| 打脸震惊类 | 装逼打脸、反转打脸、震惊全场、反差爽 | 必须有人看见，必须有立场变化 |
| 逆境崛起类 | 报仇雪恨、逆袭成功、力挽狂澜、永不屈服 | 压制越具体，爆发越有力 |
| 机遇收获类 | 一夜暴富、慧眼识珠、意外之喜、小劳大获 | 收获要有前因，不做无因天降 |
| 情感拉扯类 | 先婚后爱、替身梗、追妻火葬场、破镜重圆 | 关系变化必须有动作和代价 |
| 品格魅力类 | 平等待人、怜弱情节、人设爽、佛系赢家 | 用配角反应衬出主角魅力 |
| 心理预期类 | 期待爽、胜负欲、养成欲、无心插柳 | 让观众知道“下一步会更大” |

### 2) 使用底线

- 爽点不是乱撒弹药，必须服务主线、人物、关系和阶段任务。
- 真正的爽点要有“压制-蓄力-爆发-后果”链条。
- 打脸类爽点必须公开兑现，不能只靠主角心里爽。
- 情感类爽点必须有关系代价，不能一步跳成和好或深爱。
- 信息差爽点必须让观众知道主角掌握了什么，而反派不知道什么。

### 3) 禁止

- 为爽而爽：牺牲逻辑制造低级刺激。
- 无代价爽：主角没有选择、损失、条件或风险。
- 无见证爽：赢了但没人看见，情绪没有扩散。
- 重复爽：同一桥段换皮多次出现。
- 主角失德爽：主角伤害无辜或失去道德高地。
