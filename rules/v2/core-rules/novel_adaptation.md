## novel_adaptation（小说改编漫剧核心规则）

目标：将原著小说内容忠实浓缩成一部可拍摄的60集漫剧短剧剧本，不是重新创作，不是给出全新的故事。

---

### 1) 改编铁律（不可违反）

- **改编 ≠ 二次创作**：必须以原著为蓝本，保留核心梗、核心冲突、核心人物，不得另起炉灶
- **不得凭空创造重要反派**：只能使用原著中存在的人物，若原著反派不够，可强化已有配角，不得新造
- **核心梗必须全程在线**：每一集的创作都要为原著核心梗服务，不得中途丢失或弱化
- **改编方案必须落地**：禁止给出"增强情感张力""优化人物弧光"等教科书式空话；必须指明原著**具体哪个情节**如何改、如何删、如何调整顺序

---

### 2) 改编五步工作流

#### 步骤一：提取核心要素
- 提取原著1-3个核心梗（如：久别重逢、先婚后爱、替嫁、契约婚姻等），按重要性排序
- 提取主线人物、人物关系、人设（若原著描写不足，从对话/行为/他人评价中拼凑）
- 每个核心人物提炼1-2个鲜明性格标签

#### 步骤二：明确核心梗与基调
- 核心梗决定全剧情感走向与观众期待，基调决定创作风格
- 常见核心梗与基调对应：
  - 久别重逢 → 虐恋/错付，情感张力靠误会与遗憾堆砌
  - 先婚后爱 → 甜宠居多，冲突在从陌生到相爱的日常摩擦
  - 替嫁/冒名 → 身份悬念驱动，揭秘时刻是高光爽点
  - 契约关系 → 前期克制，情感爆发时爽感来自"破防"瞬间
- 改编全程不得出现基调割裂

#### 步骤三：筛选剧情
- **必须保留**：核心梗转折点、高光场景、标志性对话、推动主线关系的核心事件、读者最认可的经典场面
- **可以删减**：大段心理独白、与主线无关的支线、重复性铺垫、冗余背景介绍、违反平台合规要求的内容
- **可以调整**：剧情顺序（如将原著后期高光前置至开局）、内心活动外化为对话或冲突、压缩时间线

#### 步骤四：构思改编思路（必须具体）
改编思路须包含：
- **原作缺点分析**：指出具体问题（如第X章节奏拖沓、人物X行为逻辑不清等）
- **改编方向**：明确核心策略（如前置高光、压缩铺垫、外化内心戏等）
- **具体操作清单**（至少5条）：格式为"原著[具体位置/情节] → 改编处理方式（改/删/调顺序）及原因"

#### 步骤五：逐集核查
每完成一批集数须检查：
- 核心梗、核心冲突、核心人物是否完整保留，无丢失
- 有无原著不存在的原创情节或人物混入
- 各集情绪基调是否统一，无风格割裂
- 是否已删除全部不合规内容

---

### 3) 开局设计（三秒抓眼）

- 第1集前30秒**必须**有强情绪或强事件，禁止用旁白、环境描写、平淡日常开场
- 开局三选一（或组合）：
  - 强冲突开局：直接切入最具情绪张力的场景（争吵、误会、重逢、揭秘）
  - 强悬念开局：让观众困惑但急需解答的画面或台词
  - 强爽感开局：主角绝对优势或"打脸"场面，建立爽感期待
- 可将原著中期/后期的高光场景前置至开局，再以插叙/倒叙补充背景

---

### 4) 节奏与爽感要求

- 快节奏：单集不出现超过20秒的纯铺垫段落，铺垫须与情绪推进同步
- 爽感强：每5集至少一次明确爽感爆发（打脸、逆袭、破防、虐渣）
- 情绪密度：全60集均匀分布"甜/虐/爽/悬"四类情绪

---

### 5) 生稿格式（每次必交）

| 交付项 | 内容要求 |
|--------|----------|
| 改编思路说明 | 含原作缺点 + 改编方向 + 具体改动清单（至少5条落地操作） |
| 人物小传 | 每个核心人物：姓名、年龄、角色定位、性格标签、人物简介（100字内） |
| 整体故事大纲 | 全60集故事走向、核心梗发展脉络、情感高潮分布 |
| 1-10集分集集纲 | 每集单独成段，含集号、核心事件、情绪钩子（不少于150字/集） |
| 11-30集总纲 | 按阶段（每5集一段）概述走向与情感节点 |
| 31-60集总纲 | 按阶段（每5集一段）概述走向，含结局说明 |

---

### 6) 人物小传模板

每个核心人物须包含：
- 姓名（含别名/曾用名）
- 年龄
- 角色定位：男主 / 女主 / 核心反派 / 重要配角 / 工具人配角
- 性格标签（2-3个关键词，如：腹黑·冷峻·护妻狂魔）
- 外形特征（对改编有参考意义的外貌/气质描述）
- 人物背景（影响行为逻辑的核心背景，50字内）
- 人物弧光（在60集中的成长/转变轨迹，需符合四段结构）
- 标志性台词（原著中最能代表该人物性格的1-2句话）
