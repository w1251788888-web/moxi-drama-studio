## head_hit_scene_engine（头部样本场景引擎）

目标：把四个头部样本提炼出的有效推进器，转成生成阶段可执行、可自检、可验收的场景规则。

### 1) 通用硬规则
- 先锁定单义因果链：一场戏里必须有唯一的主因果口径，核心目标、核心阻碍、核心代价、核心结论各自只能有一个主说法；其他说法可以存在，但只能是误解、传闻、对立证词或阶段性判断。
- 关键设定必须分层：事实层、传闻层、推断层、裁定层、法理/制度层不能混写。凡是涉及契约、婚书、判词、通知、指令、誓约、家法、族规、系统规则等内容，先定层级，再写效力。
- 民间线索转官方结论必须有桥：从目击、听说、怀疑、猜测走到确认、定责、裁定、盖章、公开宣布，中间必须出现取证、对质、验真、第三方确认、文书流转或权威动作之一。
- 人物转向必须有桥：任何站队、和解、翻脸、认同、撤回、服软、强硬，都必须先有触发点，再有可见反应，最后有关系后果，禁止无桥转向。
- 不重复同构开局：同一集、同一题材、同一角色线不能只是换词重来。开场必须引入新信息、新动作、新后果或新压力，不能用相同姿势重复起手。
- 场内真正要推进的，不只是事件本身，而是关系状态、信息差状态、权力归属状态。
- 每场至少推进以下三者中的一项，最好两项叠加：
  - 关系变化
  - 信息差变化
  - 权力变化
- 爽点、虐点、甜点、悬念点都必须动作化，不接受只靠概括、讲道理、旁白解释。
- 真相一旦揭露，必须带出当场后果：站队变化、关系裂口、资源变动、规则惩罚、公开羞辱、公开偏爱都算。
- 每场结束都要留下“还没完”的东西：未说完的话、没做完的反击、未落地的关系、没揭完的真相、没解除的危机。
- 同一集里不能连续重复同一种推进模板；同构打脸、同构偷听、同构误会、同构栽赃必须升级或换推进器。

### 2) 四类头部样本推进模型

#### 通用桥接模型
- 线索链建议按“民间迹象 -> 现场核验 -> 第三方背书 -> 权威结论”推进，缺哪一环就补哪一环，不能直接跨层写结论。
- 立场链建议按“先怀疑 -> 再看到证据 -> 再发生反应 -> 再公开承认/公开对立”推进，禁止只写心理变化不写证据。
- 文书链建议按“先界定它是什么 -> 再写谁能用 -> 再写它改变了什么”推进，不能把证明材料、约束工具和最终裁定混为一谈。

#### A. 高压情感打脸型（参考：《非她不可》）
- 开场优先是伤害、背叛、偏爱缺席、设计陷害已经发生或马上发生。
- 爽点不是嘴上骂赢，而是证据反制、围观见证、长辈站队、资源冻结、身份压回去。
- 关系推进重点：信任裂开、站队变化、关系翻面、公开羞辱后反击。

#### B. 权力驯服 / 危险关系型（参考：《督军如此多娇》）
- 戏核不是“谁喜欢谁”，而是“谁压谁、谁立规矩、谁改规矩、谁服从谁”。
- 同一场最好同时完成关系温度变化和权力位置变化。
- 试探、惩戒、驯服、反压、示弱换权，都是这一型的核心推进器。

#### C. 错认婚配 / 秘密延迟兑现型（参考：《保密项目》）
- 第一推进器是错认、误会、信息差，不是立刻强打脸。
- 温柔、甜点、承诺都必须建立在风险没有解除、真相没有完全揭露的前提上。
- 重要钩子来自：观众知道，角色误判，真相暂时不说透。

#### D. 现实情感 / 乡土亲情型（参考：《道别是一件难事》）
- 推进不靠密集反转，而靠关系亏欠、现实压力、代际失衡、时代变化带来的余波。
- 可以克制，但不能空；每场都要有现实后果、情感余波或关系站位变化。
- 情绪爆点不一定是大吵大闹，也可以是沉默、送别、转账、看病、拥抱、没说出口的话。

### 3) 段内写法锚点

#### hook
- 前 3 行内必须端出可见异常、威胁、代价、关系裂口、身份压制、秘密露头中的至少一项。
- 禁止中性起步，禁止先介绍环境、背景、心情。
- 开场最好直接让观众产生一个具体问题：谁在骗谁、谁要失去什么、谁压着谁、谁知道了不该知道的事。

#### validation
- 这一段不是解释，而是试探、逼问、压制、误判、露证据、换站位。
- 至少让关系 / 信息 / 权力中的一项前进半步到一步，最好两项叠加。
- 每 2-3 句对白要出现一次卡点：打断、逼问、沉默、反问、拦截、半揭露。

#### explosion
- 必须把前面埋的冲突兑现成看得见的动作后果，不能只写情绪很大。
- 权力翻转要可见：谁现在更占上风，靠什么占上风，最好让第三方看见。
- 能打脸就别只骂，能亮证据就别只暗示，能公开站队就别只停在私下表态。

#### resolution
- 不是降温总结，而是把局势停在最想追问的位置。
- 结尾必须是一句具体台词、一个具体动作、一个具体发现，不是抽象感慨。
- 至少保留一条未完成承诺：真相没说完、关系没落地、报复没做完、约定被打断、危机未解除。

### 4) 自检清单
- 核心因果口径是不是只有一个主说法，其他说法有没有被清楚标成误解/传闻/反方？
- 关键设定有没有分层，尤其文书、契约、法理、口头承诺有没有混写？
- 民间线索到官方结论之间，有没有补上桥接动作？
- 人物转向是不是有触发点、可见反应和后果，而不是突然变脸？
- 这一场里，关系 / 信息 / 权力有没有至少一条真的动了？
- 爆点是不是落在动作和后果上，而不是概括句上？
- 这段戏有没有把样板剧本真正有效的推进器落出来，而不是只模仿表面词汇？
- 结尾有没有一个具体的“下一个必须发生”的东西？
