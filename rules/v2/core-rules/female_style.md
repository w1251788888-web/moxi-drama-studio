## female_style（女频对白、情绪、细节的写法）

目标：情绪有层次，细节服务关系，不写成“工整的情绪说明书”。

### 1) 对白质感
- 允许口头感：停顿、转移话题、答非所问、反问、含糊其辞。
- 情绪不直说时，用“对话策略”表现：试探、刺一句、装轻松、把话吞回去。
- 同一场里不同角色要有明显情绪处理差异。

### 2) 内心独白（OS）使用边界
- OS 只能用于：关键误会、关系转折、秘密暴露前的犹豫。
- OS 必须短：1～2 行，且每行要落到下一步行动/下一句对白。
- 禁止 OS 连续解释动机。

### 3) 情感词密度控制
- 不堆“心动/温柔/治愈/破防”等标签词来写情绪。
- 以“动作+场景细节+语气变化”替代情绪标签。
- 平台女频热题常见的情绪落点是：失望、抽离、硬撑、回头、反击、被偏爱后的迟疑。

### 4) 细节描写服务关系
- 只写能改变关系温度的细节：距离、触碰、回避、眼神停留、物品归属。
- 少写无功能装饰：漂亮的比喻如果不推进关系，就删掉。
- 豪门、先婚后爱、追妻火葬场等热题里，细节最好同时带身份差和情绪差。

### 5) 女频爆点标准
- 每场结尾最好有关系变化或秘密悬念。
- 情绪冲突要能推进下一场，而不是停在感慨里。
- 平台女频最热作品通常要求“伤害被看见 + 反击开始露头 + 关系仍有追问”。
