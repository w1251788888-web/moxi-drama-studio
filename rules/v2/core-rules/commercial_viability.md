# 商业性评估规则 v1.0
# 适用：所有步骤（market_check 门控 + concept 预判 + quality_check 维度评分）
# 数据来源：DataEye 2026Q1 + juben.pro 行业报告 + 平台热度榜实测数据

## 一、商业性评分维度（满分10分 · 5个子维度各2分）

### 子维度1：热度匹配度（2分）

| 分值 | 标准 |
|------|------|
| 2 | 命中平台当前TOP3热题材（如：霸总复仇/系统逆袭/女性成长/追妻火葬场） |
| 1 | 命中TOP4-10热题材 |
| 0 | 未命中TOP10，属冷门或已过气题材 |

**判断方法：**
- 对照平台热榜（抖音/快手/红果/微信小程序各有差异）
- 若项目定向某平台，以该平台TOP榜为准
- 若平台未知，取抖音+快手均值

---

### 子维度2：话题传播力（2分）

| 分值 | 标准 |
|------|------|
| 2 | 有3个以上"可截图传播"的金句/画面/弹幕时刻 |
| 1 | 有1-2个传播点 |
| 0 | 无可传播内容，观众看完不产生分享冲动 |

**判断依据：**
- 弹幕金句（S10爽感类型）：一句话能概括处境，听完想转发
- 场面截图：某帧画面能单独传播（如权力反转的表情特写）
- 话题议题：是否触及"有讨论价值"的社会情感点（婆媳/职场/代际）

---

### 子维度3：对标验证（2分）

| 分值 | 标准 |
|------|------|
| 2 | 有2+部成功先例（播放量过亿或付费率>8%）+ 与对标有明确差异化 |
| 1 | 有类似成功案例，但差异化不明显（同质化风险） |
| 0 | 无成功先例，或对标作品均已失败 |

**必填字段：**
- 对标作品名称（2-3部）
- 成功要素（各1句）
- 差异化策略（本项目与对标的核心区别）

---

### 子维度4：情绪价值极致度（2分）

| 分值 | 标准 |
|------|------|
| 2 | 爽/虐/甜/燃至少一项达到"极致"（每集有情绪爆发点，付费冲动明确） |
| 1 | 有情绪价值，但强度不够（"还不错"但不会为此付费） |
| 0 | 情绪平淡，无法产生付费冲动 |

**判断标准（极致的定义）：**
- 爽：观众忍不住截图分享打脸场面
- 虐：观众为角色"心疼"，主动搜索后续
- 甜：观众为糖分"嗑CP"，主动追更
- 燃：观众被激励，想立刻重刷

---

### 子维度5：平台适配度（2分）

| 分值 | 标准 |
|------|------|
| 2 | 完全符合目标平台调性、用户画像、审核尺度 |
| 1 | 基本符合，有1-2处需微调 |
| 0 | 与目标平台严重不符（调性/受众/审核均有问题） |

**各平台特征：**
- **抖音**：快节奏，视觉刺激，男女频均可，禁炫富/恶意营销
- **快手**：银发+下沉受众，情感共鸣优先，禁封建迷信/低俗，子女形象不宜全员负面
- **红果**：精品化趋势，鼓励创新，禁止同质化套路，鼓励原创设定
- **微信小程序**：中老年+三四线，情感/家庭题材，禁止诱导付费和虚假宣传

## 二、评分分档汇总

| 总分 | 判定 | 处理建议 |
|------|------|---------|
| 9-10 | 强商业性 | 优先投入资源，快速推进 |
| 7-8  | 良好商业性 | 正常推进，可优化1-2个短板 |
| 5-6  | 商业性偏弱 | **软阻断：concept 阶段警告，建议优化后继续** |
| 3-4  | 商业性差 | **硬阻断：quality_check 必须打回** |
| 1-2  | 无商业价值 | **硬阻断：market_check 门控拒绝** |

## 三、与生成流程的集成方式

### 阶段1：market_check 前置门控（方案3）

评估4项二元检查（见 00_market_check.md），结论：
- **4/4 或 3/4 通过** → 进入 concept 创作
- **2/4 通过** → 软警告，人工决策是否继续
- **1/4 及以下** → 硬拒绝，必须重新选题

### 阶段2：concept 商业性预判（方案2-B）

在概念规划输出中强制包含：
- `commercial_score`（0-10）：基于上方5维度评估概念阶段商业性
- `commercial_warnings`：低于6分时的风险说明
- **低于6分 → API 返回软警告（可强制继续，但前端显示醒目提示）**

### 阶段3：quality_check 商业性维度评分（方案1）

质检新增维度6，与其他5维度完全相同的打回逻辑：
- **任意维度（含商业性） < 6分 → 打回**
- 满分从50升为60（原创）/ 70（小说IP改编）
- 通过线从35升为42（原创）/ 49（小说IP改编）

## 四、商业性写作注入规则

### 写稿阶段（05_script_draft.md）必须命中的商业性信号

每集剧本生成时，写手必须检查：

1. **热榜命中感**：观众读完本集，能一眼感受到这是哪条热赛道（霸总/穿越/系统/宫斗...）
2. **传播点植入**：本集是否有至少1处可截图金句（台词 + 动作 + 身份差三合一）
3. **情绪价值落点**：爽感/虐感/甜感至少一项在本集有明确落点，不是"预告下集才有"
4. **付费墙服务**：若本集处于付费墙节点前后（节点A ≈ 全剧 30% 位置、节点B ≈ 80% 位置；具体集号以 `init_check_result.paywall_node_a/b` 为准，详见 `long_series.md §二`），情绪密度必须达到 4-5 个/集

### quality_check 商业性评分的触发逻辑

质检时引用 concept 阶段的 `commercial_score` 作为基准参考，同时独立评估本集剧本的商业性信号是否落地。两者不一致时（概念商业性高但剧本商业性低），按剧本实际评分为准。

## 五、投稿行业规格（2026 行业基线）

> 来源：行业公开资料整理，供 Planner 立项字数/集数设定 + Reviewer 检查交付物完整性参考。具体以目标平台/收稿方合同为准。

### 5.1 全本规格基线

| 项 | 标准 |
|---|---|
| 总集数 | 80-100 集（主流）/ 60-120 集（允许浮动） |
| 每集时长 | 1-3 分钟（竖屏） / 5-15 分钟（横屏精品） |
| 每集字数 | **以 [core/drama-format.md](../core/drama-format.md) §字数控制为准**（1 分钟档 450-550 / 2 分钟档 1100-1300）|
| 全本字数 | 约 5 万字（1 分钟档）/ 约 10-12 万字（2 分钟档）|
| 受众画像 | 35-60 岁下沉市场为主（银发+三四线）|
| 稿费区间 | 6000-15000 元/本（按质量浮动，小白单 6000-8000，头部 12000+）|
| 热门赛道 | 见 [market_validation.md](market_validation.md) 男频/女频/混合清单，本文件不重复 |

### 5.2 投稿流程与节点

| 节点 | 交付物 | 备注 |
|---|---|---|
| **初审** | 前 5 集 + 大纲 | 初审通过后续写至第 10 集 |
| **终审** | 前 10 集 + 完整大纲 + 人物小传 | 终审通过即进入签约 |
| **签约** | 合同 + 定金 | 定金 = 稿费 10%-30% |
| **交稿** | 整本 5 万字 | 签约后 25 天内完成 |

**写到卡点停笔**：投稿正文写到 6-10 集的付费卡点位置即可送审，不写完整本。

### 5.3 人物小传

人物小传的字段定义与填写要求见 [steps/02_characters.md](../steps/02_characters.md)（角色定义步骤的权威 schema），弧光推进要求见 [character_arc.md](character_arc.md)。本文件仅约束投稿阶段的**交付规格**：

- 终审必交：前 10 集剧本 + 完整大纲 + 所有主要角色小传
- 大纲 + 小传合计字数：建议 1500 字左右

### 5.4 各投稿平台调性对比

| 平台 | 特征 | 给价 | 侧重题材 |
|---|---|---|---|
| 九州 | 行业老大，收稿类型丰富 | 高 | 全品类 |
| 点众 | 爆款小说库大，改编空间大 | 低 | 改编剧本（30 集签约制）|
| 容量 | 制作精良，审核流程繁琐 | 中 | 女频精品 |
| 蜜糖 | 擅长定制，制作组强 | 低 | 定制剧 |
| 番茄 | 顶级小说库（上万部可选） | 高 | 只签爆款 |

其他：触摸、美光、掌玩、山海、花生、天桥、掌阅、麦芽、快马、聚众、华诚、爱微剧、新片场、掌中云、六翼、冰甜、天天、映客、网易、酷匠。

### 5.5 Reviewer 投稿合规检查项（交付阶段）

仅列本文件新增项；字数/人设/台词等已有规则**不在此重复**，见对应权威文件。

- [ ] **集数合规**：全本 80-100 集，偏差 >20% 警告 *（本文件权威）*
- [ ] **付费卡点位置**：第 6-10 集必须命中首次付费钩子；详细节点见 [long_series.md](long_series.md) §节点A *（引用）*
- [ ] **交付物完整**：初审=前5集+大纲；终审=前10集+大纲+人物小传 *（本文件权威）*
- [ ] **字数合规**：引用 [core/drama-format.md](../core/drama-format.md)
- [ ] **人设一致性**：引用 [character_arc.md](character_arc.md) 弧光锁
- [ ] **台词/动作具体性/画面思维**：引用 [short_drama_dialogue.md](short_drama_dialogue.md) 与 [short_drama_quality.md](short_drama_quality.md)

### 5.6 给"新手写手"的三条铁律（写入 Executor system prompt）

1. **不要铺垫**：剧本要的是画面感、强冲突、强烈矛盾。一件事直接矛盾前置，不要铺背景、不要铺起因
2. **不要想当然**：分析市场，写符合市场风向的剧本，不写自己想当然的版本
3. **模仿不是抄袭**：学写作形式（节奏/台词/框架），提取"主题框架"而非复制细节
