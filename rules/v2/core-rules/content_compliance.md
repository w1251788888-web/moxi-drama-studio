## content_compliance（平台内容合规红线）

本规则文件基于字节跳动短剧平台内容审核标准，适用于所有漫剧/短剧剧本创作。

---

### 1) 七类绝对禁止内容（一票否决）

以下内容一经出现，剧本作废，必须重写：

#### 1.1 未成年人保护
- 禁止任何涉及未成年人的性暗示、性描写、性行为内容
- 禁止美化、鼓励未成年人早恋、出走、辍学等行为
- 禁止展示未成年人遭受暴力、虐待的详细过程
- 禁止将未成年人置于色情或性张力场景中

#### 1.2 违法犯罪美化
- 禁止美化、鼓励犯罪行为（包括：盗窃、诈骗、赌博、走私、毒品交易）
- 禁止展示详细犯罪手法或将犯罪包装为"聪明""酷"
- 禁止美化黑社会、帮派文化、非法组织
- 反派犯罪行为必须有明确的道德批判或法律后果

#### 1.3 暴力与血腥
- 禁止过度血腥、残忍的暴力场面（如：肢解、内脏、大量血液）
- 禁止以猎奇、娱乐为目的的暴力展示
- 暴力冲突须服务于剧情，不得成为视觉刺激目的本身
- 禁止美化校园暴力、家庭暴力

#### 1.4 封建迷信与伪科学
- 禁止宣扬封建迷信（如：算命、卜卦）为真实有效的能力
- 禁止以"科学证明"的方式传播伪科学内容
- 玄幻/仙侠题材中的超自然元素须明确为虚构设定
- 禁止宣扬邪教、极端宗教内容

#### 1.5 政治敏感内容
- 禁止涉及台湾、西藏、香港等政治敏感议题的不当内容
- 禁止歪曲历史事实、丑化历史人物
- 禁止含有分裂国家、煽动民族矛盾的内容
- 涉及历史背景须符合官方认定

#### 1.6 色情与低俗
- 禁止露骨性描写、性行为描述
- 禁止以暗示、隐喻方式的软色情内容（如：夸张的喘息声、过度强调身体部位）
- 禁止物化、羞辱女性/男性的内容
- 亲密场景仅允许：拥抱、牵手、轻吻，须有情感铺垫

#### 1.7 赌博与金融违规
- 禁止展示赌博场景（包括：地下赌场、线上赌博平台）
- 禁止任何形式的金融诈骗美化（如：杀猪盘、传销）
- 禁止展示非法集资、地下钱庄等犯罪活动细节

### 2) 灰色地带处理规则

以下内容须谨慎处理，需加入明确的价值导向：

| 内容类型 | 允许范围 | 必须包含 |
|---------|---------|---------|
| 婚外恋/出轨 | 可作为剧情冲突 | 明确的道德批判结局 |
| 复仇情节 | 可作为主线驱动 | 不能美化违法复仇手段 |
| 霸道总裁 | 可作为人设标签 | 不得美化控制/PUA行为 |
| 赘婿/白手起家 | 可作为逆袭核心 | 须通过正当手段实现 |
| 家庭矛盾 | 可作为戏剧冲突 | 不得美化家暴/遗弃行为 |
| 豪门争产 | 可作为悬念设计 | 不得以犯罪手段为正途 |

### 3) 自查清单（每集必查）

完成每一集剧本后，逐项核对：

- [ ] 本集是否涉及未成年人敏感内容？
- [ ] 是否有美化犯罪行为的场景？
- [ ] 暴力场景是否超出必要尺度？
- [ ] 是否含有政治敏感表达？
- [ ] 亲密场景是否符合平台尺度？
- [ ] 反派行为是否有明确的道德或法律后果？
- [ ] 是否含有宣扬封建迷信的内容？

---

### 4) 合规修改原则

发现违规内容时，优先采用以下修改方式（按优先级排序）：

1. **场景替换**：将违规场景替换为同等戏剧效果的合规场景
2. **结果调整**：保留场景但添加明确的负面后果/道德批判
3. **镜头剪辑**：通过叙事方式跳过违规细节，保留前因后果
4. **情节删除**：无法修改的情节直接删除，用其他情节补充戏剧张力

**禁止**：以"艺术表达""剧情需要"为由保留违规内容
