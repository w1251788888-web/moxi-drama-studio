## female_core（女频核心驱动）

### 1) 场内闭环
- 每场必须清楚写出：关系现状 → 触发事件 → 试探/对抗 → 关系温度变化 → 结果。
- 结果必须可见：靠近/疏远/误会加深/信任裂缝/依赖增强/权力交换。

### 2) 试探与拉扯
- 试探要具体：一句话、一件小事、一个边界动作。
- 拉扯不靠长篇内心解释：用“没说完的话”“不对称回应”“动作抢先”表现。
- 平台女频热题更偏女性成长、打脸虐渣、豪门、追妻火葬场、先婚后爱，关系推进必须和这些代价结构绑定。

### 3) 情感钩子与命运悬念
- 结尾钩子优先用“关系代价/秘密暴露/承诺被逼兑现”。
- 不用大道理收束，不用总结式旁白。
- 平台女频热赛道要求第一集就能看见伤害、偏爱缺席、身份落差或关系裂口。

### 4) 情绪推进原则
- 情绪不是一直高；要有试探、失衡、忍住、爆发、回收的层次。
- 每集至少有一次关系位置变化。
- 女性成长类不要只写受伤，要尽快写出反击、抽离或清醒选择。

### 5) 女频的”可追看感”
- 观众要看到角色之间的偏爱、误会、拉扯、回头、失去与挽回。
- 事件只是让关系变得更难、更近或更危险的工具。
- 平台女频高频题材都要求情绪与现实后果并行，不能只甜不痛，也不能只痛不翻。

### 6) 头部女频样本的三种强推进模型

#### A. 高压情感打脸型（参考：《非她不可》）
- 关系推进依赖：伤害被看见、秘密暴露、证据反制、长辈或高位者站队。
- 爽点优先是“公开反击 + 权力易手”，不是单纯台词骂赢。
- 前 1-3 场就要让观众知道：谁在伤害女主、谁在隐瞒、谁会为此付代价。

#### B. 权力驯服 / 危险关系型（参考：《督军如此多娇》）
- 关系推进不能只写温度，要写谁立规矩、谁改规矩、谁服从谁。
- 拉扯通过试探、惩戒、反压、示弱换权完成。
- 同一场最好同时完成“关系温度变化 + 权力位置变化”。

#### C. 错认婚配 / 秘密延迟兑现型（参考：《保密项目》）
- 核心推进器是错认、误会、秘密、承诺被打断。
- 甜点必须建立在风险未解除之上，不能把危险消掉再撒糖。
- 钩子优先来自“观众知道 / 主角误判 / 真相暂不揭”。

### 7) 精品现实情感分支【2026新方向】
> 适用于：不依赖豪门/逆袭/重生套路、以人物关系和情感共鸣驱动的精品化女频短剧（代表：《红糖姜汁》）
- **开场驱动不是强冲突，而是”关系失衡+情感缺口”**：第一场展示一个关系裂口或情感空缺，观众感知到”某种东西正在慢慢流失”
- 节奏允许前1-2场以关系温度铺垫，但必须在第3场前出现至少一次可见的情绪落差
- 不依赖打脸/身份逆袭，而靠”被看见的那一刻”积累追看动力
- 钩子类型以关系钩子为主：偏爱出现/误解加深/某人开始动摇
- **此分支规则不替代主规则**，仅在项目类型为”精品情感”时启用；标准女频爆款项目仍遵循主规则

### 8) 现实亲情 / 乡土情感分支补充（参考：《道别是一件难事》）
- 推进不靠密集反转，靠关系亏欠、现实困境、代际压力和时代变化。
- 可以克制，但不能空；每场都要有现实后果、情感余波或关系站位变化。
- 现实细节本身就是戏：医院、车站、罚单、债务、上坟、空村、送站，都可以承担推进功能。
- 情绪爆点不一定是争吵，也可以是拥抱、送钱、送别、没说出口的话。
- 这一路数的钩子更适合“关系还没说完、告别还没完成”，而不是生硬悬疑。
