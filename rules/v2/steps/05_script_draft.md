## 【验收版格式规范】（甲方第一版验收格式，凡生成剧本必须严格遵守）

**场次标头格式（由 pipeline.toml [project_format] scene_header_style 决定）：**

`bracket` 模式（默认，甲方验收稿）：
```
【场1-1：夜  内  江家书房】
```

`plain` 模式（平台投稿稿）：
```
1-1  日  外  战场
```

当前项目使用：`${scene_header_style}`

⚠️ 两种格式全集必须统一，不得混用。禁止自行决定格式，必须读取 `${scene_header_style}` 变量。

**人物行格式：**
```
人物：角色A，角色B，角色C
```
- 逗号分隔，不加括号

**内心独白格式（角色内心想法，不出声）：**
```
角色名OS：内容
角色名（情绪）OS：内容
```

**离镜画外音格式（角色在镜外说出来的话）：**
```
VO（角色名）：内容
```

**机制/系统/神器发声：**
```
铜镜VO：内容
系统VO：内容
```

**音效/环境声：**
```
VO：轰！
VO：叮——
```

- `OS` = 内心独白，角色没有说出口；`VO（角色名）` = 角色在镜外开口说话；两者**不可混用**

**叙述性旁白VO（角色解说世界观/情境）：**
```
角色名VO：这个世界人妖并立，妖族以人为食……
```
- 格式：`角色名VO：内容`（角色名直接连VO，无括号）
- 用途：角色以旁白身份向观众快速解说背景/规则/世界观，不是实时对话

**【VO+快剪】世界观速览格式（漫剧专用）：**
```
【VO+快剪】
角色名VO：这个世界……（第一段解说）
快剪画面：（对应的视觉描述）
角色名VO：……（第二段解说）
快剪画面：（对应的视觉描述）
【快剪结束】
```
- 用途：穿越/重生/系统激活后，快速向观众传递世界观规则，最多3段
- 每段VO不超过30字；每段快剪画面1-2句可视化描述
- 此格式出现时机：第1集角色初次进入新世界，发现规则异常后触发

**角色首次出场字幕：**
```
△角色走进教室。【字幕：江流】
△考官走上台。【字幕：考官姓名 职位/境界】
```
- 格式：`【字幕：角色名】` 或 `【字幕：角色名 身份/境界】`
- 必须在角色**第一次出现**时标注，写在该角色的△动作行末尾
- 后续出场不再重复标注

**状态/境界升级字幕：**
```
△字幕改变：先天一重……先天二重……先天三重！
△江流睁眼，金光散去。【字幕：江流 先天三重境】
```
- 境界飞速提升时用`△字幕改变：`逐级显示
- 稳定后用`【字幕：角色名 当前境界】`标注新状态

**舞台提示/动作描写：**
```
△角色抬起头，目光落在铜镜上。
```
- 以 `△` 开头，不加括号，不写"动作："标签

**台词格式：**
```
江寧：你说的是真的？
```
- 直接写 `角色名：台词`，无需其他标记

## 【修复56】人物状态变化卡（每集必填，防角色弧线停滞）

写本集前必须完成"人物状态变化"自检，并将变化体现在剧本中：

| 角色 | 上集状态 | 本集状态 | 转变触发动作 |
|---|---|---|---|
| 主角 | 从 ${state_cards_block} 中本集前的"主角状态"读取 | 本集结束时主角的内在状态 | 本集中导致变化的具体场景/对白/事件 |
| 反派 | 同上 | 同上 | 同上 |

**强约束**：
- 主角和反派的"本集状态"**不能**与上集完全相同
- 主角必须在本集出现至少 1 次"内在变化触发瞬间"——通过 OS、表情特写、动作犹豫体现
- 例：恐惧→坚定 / 犹豫→决断 / 独自→结盟 / 被动→主动 / 复仇→放下
- 反派必须在本集失去某些东西（资源/同伙/底牌/信用 之一）

**禁止**：
- 主角 30 集都是"调查/揭露/反击"同一种状态
- 反派 30 集都是"嘲讽/愤怒/离场"同一种反应
- 用空泛词汇代替具体变化（"变得更坚强了" "渐渐成熟" 不算变化）

## 漫剧字数硬约束（project_type 含"漫剧"时强制执行）

本集剧本正文净字必须严格落入按 `${episode_minutes}` 换算后的目标区间；基准为 **90秒 = 1150～1250 纯字符**（不含标点与空白）。

**【修复52 字数倒推 — 必读】**
1. **看 `${scene_list}` 数有几场**（设为 N）
2. **每场目标字数 = 当前时长目标净字 / N**（如 90秒约1200字，6 场 → 每场约200字；5 场 → 每场约240字）
3. **每场必须真写满该字数**——下面是各场最小字数预算：

| 场次数 N | 每场目标 | 每场最少 | 每场最多 |
|---|---|---|---|
| 5 | 240 字 | ≥220 字 | ≤280 字 |
| 6 | 200 字 | ≥190 字 | ≤230 字 |
| 7 | 170 字 | ≥160 字 | ≤200 字 |

**【修复66 禁止多场短场】**：
- 漫剧每集**严格 5-7 场**，**禁止 8 场以上**（多场会导致单场 < 150 字"碎片化"）
- 单场字数 < 150 字判废，必须合并到相邻场次
- 单场字数 > 350 字判废，必须拆分（但拆分后总场数仍要 ≤ 7）

4. **写完每一场都要在脑内统计**：本场预估字数 ≈ ?
5. **整集合计 < 1150**：必须回到字数最少的那 1-2 场补足，不要重写已写完的爽感场

**修剪/补充策略**：
- 字数过多（>1250）：删冗余动作描述、压缩过长台词、合并节奏相同的短场次；**多余推进允许拆到下一集**（在 context_output 注明"以下情节拆至第 N+1 集：..."）
- 字数不足（<1150）：**禁止用扩写凑字**，必须按场补充：
  1. 检查每场是否都有 ≥1 行 △ 动作 + ≥2 行台词 + ≥1 行 OS
  2. 扩充关键爽感爆发场的动作层次（围观反应、表情特写、道具特写）
  3. 增加场末钩子的视觉细节（最后一帧定格画面）
- 字数统计行（仅供内部校验，不计入正文）：在 context_output 中报告实际字数

**禁止**：
- 禁止把整集压缩到 800 字以下（这是不合格 + 触发重写）
- 禁止给单场超过 350 字（节奏失温）
- 禁止用空白对白或重复 OS 凑字数

真人短剧无此硬约束，但同样需要控制节奏，单场不超过 400 字。

## 爽感爆发场写法规则（所有项目）

节拍表中标注的爽感爆发点，在剧本中落地时必须满足：
1. **围观性**：爽感不能只有主角自己知道，必须有第三方在场（或第三方将要知道）
2. **可视性**：爽感必须外化为动作/表情/道具/场面，不能只靠内心独白
3. **立即兑现**：爽感爆发后必须在本场/本集内兑现后果，不能只埋不炸
4. 漫剧专用：爽感爆发场允许使用”夸张化动作描述”（如：他的表情凝固成化石/整个人像被雷劈）

## 内心独白与画外音格式规则【2万案例验收标准】

**格式对照（来源：龙君 + 战场合同工）：**

| 类型 | 格式 | 说明 |
|------|------|------|
| 内心独白 | `角色名OS：内容` 或 `角色名（情绪）OS：内容` | 角色没有说出口的想法 |
| 离镜画外音 | `VO（角色名）：内容` | 角色在镜头外开口说话 |
| 机制/系统 | `铜镜VO：内容` / `系统VO：内容` | 神器/系统发声 |
| 音效 | `VO：轰！` | 环境音、音效 |

**OS使用频次（漫剧）：** 每集主角 OS **3～6 次**（低于 3 次节奏失温，超过 6 次则堆砌感过强，两者均视为不合格）

**OS 触发时机（至少命中 3 种/集）：**
1. 信息落差时：主角掌握观众不知道的情报 → OS 点明战略意图
2. 危机评估时：角色面对未知威胁 → OS 外化判断过程
3. 爽感爆发前：主角出手前的一瞬间 → OS 锁定目标
4. 围观震惊时：旁观者看到爽感 → OS 传递”服了/怎么可能”

**机制 VO 规则（按角色卡中标注的机制类型分支执行）：**

**若机制类型 = 系统型（属性面板/技能解锁/数值播报）：**

三选二原则——每次发声必须包含以下至少2项：
1. 状态变化（发生了什么 / 检测到什么）
2. 具体内容/能力名称
3. 下一步方向

示例：`系统VO：宿主突破先天一重，技能【淬体术】解锁，下一阶段任务已刷新。`

**若机制类型 = 人格型（镜中真实人物/情感对话型）：**

- **禁止**使用系统公告格式（禁止"确认——""检测到""解锁"等系统用语）
- 必须以"有情感、有死亡气息的真实人物"口吻说话
- 信息允许不完整——濒死者/历经沧桑者不需要把所有情报说清楚
- 情感优先于信息完整性：先建立情绪连接，再传递关键线索
- 发声节奏：可停顿、可打断、可只说半句

