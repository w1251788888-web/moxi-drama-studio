# 尾钩多样化规则

## 禁止单一化

❌ 禁止连续使用"反派筹谋报复"型尾钩

## 五类尾钩轮换

### 1. 悬念型（发现/揭露）

主角发现新线索、新危机或真相的一角。

示例：
- 江寧发现指纹属于熟人
- 神秘包裹里有母亲的遗物
- 监控录像显示另一个身影

### 2. 关系型（人物/情感）

关键人物出现、关系转折或情感升温。

示例：
- 李梓沐突然出现
- 死对头出手相救
- 暧昧对象误会加深

### 3. 代价型（后果/风险）

主角承担行动后果，或暴露隐藏身份。

示例：
- 身份即将被公开
- 帮助主角的人被报复
- 秘密行动被监控拍到

### 4. 升级型（任务/挑战）

新任务发布、挑战升级或局势扩大。

示例：
- 系统发布新任务
- 反派提升打击力度
- 更大的势力介入

### 5. 反转型（预期/落差）

预期落空、局势逆转或真相翻转。

示例：
- 以为赢了其实是陷阱
- 盟友其实是敌人
- 看似失败实则成功

## 轮换检查

排集前检查前3集尾钩类型，确保当前集使用不同类型。

## 附录：十一种断集钩子细分标签（v1.1）

**用途**：在上方5大类（悬念/关系/代价/升级/反转）之上，为 Executor 生成钩子时提供更细颗粒度的选型标签；Reviewer 检查钩子多样性时可引用本标签检测是否连续使用同一子型。

| 标签 | 名称 | 结构 | 隐含悬念问题 | 归属主类 |
|---|---|---|---|---|
| H1 | 预示冲突 | 有人找主角对决/宣战 | 谁会活下来？ | 升级型 |
| H2 | 秘密 | 同伴藏信/锁盒/未拆包裹 | 内容究竟是什么？ | 悬念型 |
| H3 | 重要决定或誓言 | 主角当众发誓报仇/立约 | 他会怎么做？能否成功？ | 升级型 |
| H4 | 宣布震惊事件 | 突然通报死亡/破产/背叛 | 如何发生？主角如何面对？ | 代价型 |
| H5 | 激烈情绪 | 角色遭不公待遇情绪爆发点 | 他会如何发泄？会否崩塌？ | 关系型 |
| H6 | 颠覆性突转 | 已认定的事实被推翻（母亲未死/盟友是敌人） | 真相是什么？如何应对？ | 反转型 |
| H7 | 新想法 | 主角想到对付反派的新方案 | 方案是什么？能否奏效？ | 升级型 |
| H8 | 未回答的问题 | "你其实不是他对不对？" | 他到底是不是？为什么伪装？ | 悬念型 |
| H9 | 神秘对白 | "午夜到诺斯桥，一个人来" | 答案是什么？为什么地点/时间特殊？ | 悬念型 |
| H10 | 预言/异象 | 战场日食、诡异征兆 | 天象预示着什么？ | 悬念型 |
| H11 | 转折点 | 主角被送孤儿院/流放/入狱 | 新环境下如何生存？ | 代价型 |

### 使用规则
- 每集 `end_hook` 字段除填写主类外，附加子标签（如 `反转型/H6`）。
- **连续3集禁止出现同一子标签**（比5大类层粒度更严）。
- 漫剧/AI 仿真人短剧优先使用：H1、H4、H6、H11（视觉冲击强）。
- 真人短剧优先使用：H2、H5、H8、H9（关系与悬念内化表演）。
- H3、H7 慎用于女频情感线（易脱离情绪共振）；H10 仅限古装/玄幻/悬疑。

### Reviewer 检查逻辑
在 `quality_check` 的"钩子多样性"维度中，检测本集钩子标签在前3集中是否重复：
- 重复 → 扣1分并提示替换建议（从同一主类的其他子标签中挑选）。
- 连续3集同子标签 → 硬打回。
