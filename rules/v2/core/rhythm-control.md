# 节奏控制规则

## 核心原则

**120秒 = 1200 有效汉字**（即 10 字/秒，有效字不计标点）

字数权威定义见 `core/drama-format.md §字数控制`，本文件各场字数均以此为基准分配。按短剧拍摄时长反推字数上限，收紧场次和台词密度。

## 分场结构

标准5场结构：

| 场次 | 字数 | 功能 | 情绪曲线 |
|------|------|------|----------|
| 场景1 | 200-250 | 铺垫/引入 | 平或微升 ↗ |
| 场景2 | 250-300 | 发展/冲突 | 上升 ↗ |
| 场景3 | 250-300 | 转折/升级 | 继续上升 ↗ |
| 场景4 | 200-250 | 高潮前 | 最高点 ↗ |
| 场景5 | 150-200 | 尾钩 | 悬念/下落 ↘ |

## 节奏控制要点

### 1. 装X密度

- 同一集内高光时刻不超过 2-3 次
- 同一天内装X不超过 3 次
- 重大高光之间必须：跳天、铺垫、压制或关系变化

### 2. 情绪曲线

- 避免单调上升或下降
- 标准模式：平→升→升→顶→悬
- 每集必须有情绪起伏，不能平铺直叙

### 3. 场景切换

- 场景切换要有明确动机
- 避免无意义的转场
- 用字幕（△）提示时空变化

## 字数检查

生成后必须统计：
- 有效中文字符数（不含标点、空格）
- 如超过1300字，拆分为两集或精简
- 如不足1100字，增加细节或场景

## 尾钩设计

尾钩类型轮换使用：

1. **悬念型**：发现新线索/新危机
2. **关系型**：关键人物出现/关系转折
3. **代价型**：主角承担后果/暴露风险
4. **升级型**：系统任务/新挑战
5. **反转型**：预期落空/局势逆转

禁止连续使用同一类型尾钩。更细颗粒度的 H1-H11 子标签见 [hook-patterns.md](hook-patterns.md#附录十一种断集钩子细分标签-v11)。

## 分层与打断（场内节奏微观法则）

> **职责边界**：硬规则（每 2-3 段对白一次卡点、每场一次目标阻断、每场一次局势翻向）以 [short_drama_rhythm.md](../core-rules/short_drama_rhythm.md) §2 "场内推进" 为准。本节是 Reviewer 判定"冗长/节奏塌方"的**判定准则**，不重复那里的硬约束。

**定义**：分层是节奏感的象征——一部剧节奏好不好看分层做得好不好，分层的要点在于何时打断、分到下一层。

### 判定分层节点（以下时刻必须切下一层）
1. **情绪变化节点**：角色或观众情绪突变时（如从紧张转为放松、从压抑转为爽感）
2. **信息发现节点**：观众或角色得到新信息、揭露隐藏事实
3. **时间发展节点**：跳日、跳场、回忆闪回进出
4. **事件升级节点**：冲突烈度提升、身份层级切换（如从底层反派跳到中层反派）
5. **反转节点**：剧情朝相反方向发展

### 打断的操作手法
- 当前一层的**信息已介绍完成、情绪目标达成**后，事件本身往往还没结束 → 这时用**突然的意外因素介入**把上层打断，推进到下一层
- 连贯事件的升级不必强制分层，直接升级即可（观众不需感知到明显切层）
- 话题改变可以再细化一层（如一组争执戏中话题从"家产"升级到"身世"就是新子层）

### 反面信号（Reviewer 应警示）
- 单场戏 3 分钟以上无分层 → 冗长，标记"节奏塌方"
- 情绪线一路单调上升或下降 → 缺分层节奏
- 事件结束后仍在同一层反复消耗 → "无效延长"，建议压缩或直接切

### 与场景切换的关系
- **分层** 是情绪/信息/事件的切层，不一定换场
- **换场** 是物理空间切换，必须伴随分层才有意义（否则是无意义转场）
- 每集标准分层数：竖屏短剧 **6-10 层 / 2分钟**，横屏精品 **8-12 层 / 10分钟**

## 观众错觉（反转的进阶用法）

**定义**：普通反转 = 事件朝与正常发展相反方向走；错觉 = 故意让观众以为事情会朝 A 方向走，结果朝 B 方向。

**操作要点**：
- 错觉通常用于短剧的"拉扯"——当观众以为事情朝自己期待方向反转后，下一层或下一集却出乎意料
- **错觉必须合理**：反面例子——上一集用镜头语言让观众以为母亲看到女儿幼年信物，下一集继续骂女儿，信物"没看到"。这种生硬错觉观众会反感
- 错觉做得越合理，观众对剧的感观越好
- 每 5-8 集必须有一次合格错觉，避免观众提前预判剧情走向

## 反差对比（零铺垫升情绪法）

**无需铺垫**即可制造新奇感、喜感、陌生感、探究欲、情绪升级：
- **人物形象反差**：霸总私下吃饭不修边幅 / 温柔暖男偶露霸气
- **戏剧性反差**：贫穷与富有 / 幸福与灾厄并置（万家灯火之时，孤苦者卖火柴）
- **身份反差**：主角平时伪装废物，某一瞬间露出真实身份的一缕

短剧开场 30 秒必须出现至少一次可视反差；每集至少 2 次反差对比节点。
