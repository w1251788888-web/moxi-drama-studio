# 短剧剧本格式规范

## 基本结构

```markdown
# 第X集：集标题

## 场景N 地点/时间

△字幕：时间/地点提示

动作描述（简洁，有画面感）

角色名
（情绪/动作提示）
对白正文

角色名（OS）
内心独白

角色名（VO）
离镜发声（电话中、门外等）

【VO+快剪】
快速剪辑指示

△字幕：角色名 身份
人物介绍字幕

△字幕改变：新提示
字幕变化
```

## 标记符号规范

| 符号 | 含义 | 示例 |
|------|------|------|
| `（OS）` | 内心独白 | 江寧（OS）<br>不对劲... |
| `（VO）` | 离镜发声 | 李梓沐（VO）<br>你等我 |
| `【VO+快剪】` | 快速剪辑 | 【VO+快剪】<br>闪过前几集画面 |
| `△字幕：` | 画面字幕 | △字幕：三天后 |
| `△字幕改变：` | 字幕变化 | △字幕改变：真相浮现 |

## 排版规则

1. **集标题**：`# 第N集：标题`
2. **场次**：`## 场景N 地点/内/外/时间`
3. **角色名**：单独一行，顶格
4. **对白**：角色名下一行，顶格
5. **动作**：单独段落，描述画面动作
6. **空行**：场景之间、角色对白之间留空行

## 禁止的格式

❌ 说明式分场稿（"这场讲江寧回家"）
❌ 动作/对白栏目表格式
❌ 普通大纲体（没有标准剧本排版）
❌ 过度详细的镜头指示（留给分镜）

## 字数控制

- 单集：1100-1300 有效中文汉字（不计标点）
- 场景1：200-250字
- 场景2：250-300字
- 场景3：250-300字
- 场景4：200-250字
- 场景5：150-200字（尾钩）
