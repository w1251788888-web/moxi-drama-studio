# 嘉豪系短剧核心写作逻辑

## 一、关系推进逻辑

- 人物关系按"日常慢推、事件跃迁"处理
- 日常情境只能推进轻微好感、态度松动、局部护短、额外关注
- 明显关系升级必须由高强度事件换取：救人、共患难、承担风险、共享重大秘密
- 每次关系升温后都要评估余波与代价：误会、舆论、压力、被反派盯上

## 二、反派设计逻辑

- 反派不能只承担"被打脸前的挑衅者"功能
- 反派阻力必须分层：校园级羞辱与嫉妒、规则级卡位、资源级压制、情感级搅局
- 反派每次出手都应有明确目标：争面子、抢资源、保地位、毁关系
- 反派不必每次都惨败到底，可以小输但留下后手

## 三、分集爽点逻辑

- 分集之间不能连续重复"被质疑—公开测试—当众自证—打脸"模板
- 每集主戏核必须明确区分：关系推进、身份误判、颜值变化外显、规则陷阱、资源争夺、误会反转、代价暴露
- 同一天内装X次数不要超过3次
- 重大高光之间必须靠跳天、铺垫、压制或关系变化拉开间距

## 四、质感保留逻辑

- 改稿以"微创修正"为先，不推翻已成立的观感、人物气质和场面感觉
- 控字数靠切集，不靠压扁写法、不靠骨架化推进
- 第4集的观感应作为质量基准：单一戏核、细节更密、微反应更足、情绪更自然、爽点更扎实
- 第6集后也必须保持前期的细节密度
- 配角要承担助攻功能，热梗可用但必须自然贴场景
