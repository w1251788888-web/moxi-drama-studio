# 人物关系推进规则

## 核心逻辑：日常慢推、事件跃迁

### 日常推进（微增量）

日常情境只能推进：
- 轻微好感
- 态度松动
- 局部护短
- 额外关注

**禁止**：平地起高信任、强暧昧、关系跳级

### 事件跃迁（质变）

明显关系升级必须由高强度事件换取：
- 救人/被救
- 共患难
- 承担风险
- 共享重大秘密
- 公开站队支持

### 余波与代价

每次关系升温后必须评估：
- 误会风险
- 舆论压力
- 被反派盯上
- 其他关系受损

**不允许**：关系线无代价飙升

## 应用流程

设计每集时：

1. 判断本集类型：日常推进 / 事件跃迁
2. 日常戏 → 只写微增量关系触点
3. 跃迁戏 → 先补足高压事件，再补写余波
4. 禁止直接硬推情感结果

## 关系状态标记

在角色卡中记录关系张力值（0-1）：

| 值域 | 状态 |
|------|------|
| 0-0.2 | 陌生/敌意 |
| 0.2-0.4 | 认识/缓和 |
| 0.4-0.6 | 友好/合作 |
| 0.6-0.8 | 信任/暧昧 |
| 0.8-1.0 | 亲密/依赖 |

单集关系变化幅度：日常±0.05，事件±0.2
