# 付费墙公式（W3-A #3）

**用途**：8-12 集首付墙（is_paywall_a）+ 26-28 集二付墙（is_paywall_b）的钩子设计权威指南。
**数据源**：拆解样本（千金谋/盛夏芬德拉/十八岁太奶 3）+ 知识库 236 本付费集分析 + 104 集人评中第 8-12 集失败原因。
**版本**：v1.0（2026-05-03）。

---

## 付费墙是什么

短剧免费集到付费集的转折点。观众必须**强烈想看下一集**才会付费解锁。
- **首付墙**（第 8-12 集）：决定**首充率**——观众第一次掏钱
- **二付墙**（第 26-28 集）：决定**回流率**——观众持续追订到结局

**核心定理**：付费墙集次的 cliffhanger **必须比其他集强一倍**——单层钩子不够，必须**多层钩子叠加 + 关键人物意外行动**。

---

## 首付墙公式（第 8-12 集，is_paywall_a）

### 公式：未兑现期待 × 多重悬念 × 关键人物突变 × 时间压力

四要素**至少命中 3 项**才能称为合格首付墙。

#### 要素 1：未兑现期待
前 7 集积累的最强情绪期待（复仇/相认/翻身/告白），在本集集末被打断、悬置或反向。

| 形态 | 例 |
|---|---|
| 期待被拦腰打断 | 主角即将公开反派罪行 → 关键证据被烧 |
| 期待被反向引爆 | 男女主即将相认 → 男主身份被冒名顶替 |
| 期待被加倍提级 | 即将拿回家产 → 发现还有更深阴谋 |

#### 要素 2：多重悬念
集末同时埋 ≥ 2 条独立悬念线，下集开场必须先解决一条但留另一条。

#### 要素 3：关键人物突变
某个关键角色的**身份/立场/状态**发生本集第一次披露的剧变（不是前几集已铺垫的）。
- 反派一直暗中操控，本集突然揭示真身是主角"最信任的人"
- 配角看似工具人，本集突然反水

#### 要素 4：时间压力
集末必须有"必须在 X 时间内/X 行动前完成"的明确时间窗。
- 24 小时内 / 婚礼前 / 庭审开庭前

---

### 首付墙的 6 种成熟模式（按使用频次降序）

| 模式 | 结构 | 适用赛道 |
|---|---|---|
| **A 身份炸雷** | 关键角色（亲人/盟友/爱人）突然被揭露非真实身份 | 女频霸总/古装宫斗/重生复仇 |
| **B 证据失踪** | 主角即将赢的关键时刻，决定性证据被偷/烧/篡改 | 都市重生/悬疑犯罪 |
| **C 至亲危机** | 至亲突遭重伤/绑架/濒死，主角必须暴露最后底牌 | 男频战神/系统流 |
| **D 地位倒翻** | 主角刚翻盘 → 立刻被打回原点 + 多个新对手登场 | 古装宫斗/职场逆袭 |
| **E 死讯反转** | 已确认死亡的角色突然现身 / 已确认活着的角色被宣告死亡 | 玄幻修仙/古言 |
| **F 双线相撞** | A 线终于解开 → 触发 B 线更大危机 | 悬疑犯罪 |

### 首付墙 cliffhanger 必填字段（与 02b_episode_outlines 对齐）

```json
{
  "is_paywall_a": true,
  "freeze_scene": "具体场所（必须是前文未出现的高情绪压力空间）",
  "freeze_characters": ["≥ 3 个角色，包含主角 + 反派 + 1 个意外角色"],
  "freeze_prop": "可视高象征道具（账本/电报/血书/婚书/通缉令）",
  "freeze_action": "动作必须包含『即将发生但未发生』的悬置感（话说一半 / 手指停在按键 / 门即将推开）",
  "hook_subtag": "推荐 H4 震惊宣布 / H6 颠覆突转 / H11 转折点",
  "open_promises": ["≥ 2 条本集集末未兑现的承诺，下集必须接"]
}
```

### 首付墙常见失败案例（来自人评低分集）

- ❌ 集末只有"反派愤怒离场" → 弱钩子，无新信息
- ❌ "故事继续/真相未明/期待下集" → 抽象悬念，不可视
- ❌ 钩子是"主角下定决心" → 内心戏，不是外在动作
- ❌ 与前 3 集 hook_subtag 完全相同 → 子标签重复扣分

## 二付墙公式（第 26-28 集，is_paywall_b）

### 公式：全剧最大爽感**前夜** × 主角看似已死/已败 × 反派看似已胜

二付墙是"高潮前的至暗时刻"，让观众强烈想看到最终反转。

#### 必备结构

| 元素 | 内容 |
|---|---|
| **主角状态** | 重伤 / 假死 / 落难 / 被全员背叛 / 失忆 |
| **反派状态** | 看似已掌握全局 / 庆祝胜利 / 策划终局 |
| **观众情绪** | 揪心、不甘、期待主角王者归来 |
| **集末画面** | 主角倒下/消失 + 反派笑容 + 关键道具仍在场（埋反转伏笔） |

#### 二付墙 cliffhanger 必填字段

```json
{
  "is_paywall_b": true,
  "freeze_scene": "强对比场所（葬礼/废墟/反派庆功宴）",
  "freeze_characters": ["主角处于极弱位置 + 反派阵营围观 + 1 个隐藏的反转伏笔角色"],
  "freeze_prop": "反转钥匙道具（主角戒指/血书/未兑现的承诺物）",
  "freeze_action": "反派宣告胜利 + 关键道具被特写 + 观众知道主角未真死",
  "hook_subtag": "推荐 H6 颠覆突转 / H11 转折点",
  "ironic_signal": "给观众的反转暗示（反派露出破绽 / 主角藏起钥匙 / 旁白吐槽）"
}
```

#### 二付墙常见失败案例

- ❌ 主角真的死了 → 观众无期待
- ❌ 反派直接被反杀 → 错过付费窗口
- ❌ 主角"暂时认输"但没有反转伏笔 → 观众不知道还能反扑

## 使用顺序

1. **concept 阶段**：在 season_milestones 标注 ep8-12 / ep26-28 哪一集是付费墙
2. **02b_episode_outlines 阶段**：付费墙集次在 outline JSON 设 `is_paywall_a/b: true`
3. **05_script_draft 阶段**：付费墙集次的最后一场必须严格按上述模式 A-F 落地
4. **07_quality_check 阶段**：reviewer 校验付费墙四要素命中 ≥ 3 项，否则整集打回
