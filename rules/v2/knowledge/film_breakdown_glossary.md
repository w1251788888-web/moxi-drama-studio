# 拉片词典（W3-A #6）

**用途**：统一全流程（concept / beat_sheet / scene_list / script_draft / quality_check / reviewer）的专业术语，避免各步骤"说不同的话"。
**版本**：v1.0（2026-05-03）。

---

## 一、钩子术语

### 五大主类（来自 [hook-patterns.md](../core/hook-patterns.md)）
| 主类 | 简称 | 一句话定义 |
|---|---|---|
| 悬念型 | 悬念 | 主角发现新线索/新危机/真相一角 |
| 关系型 | 关系 | 关键人物出现 / 关系转折 / 情感升温 |
| 代价型 | 代价 | 主角承担行动后果 / 暴露隐藏身份 |
| 升级型 | 升级 | 新任务发布 / 挑战升级 / 局势扩大 |
| 反转型 | 反转 | 预期落空 / 局势逆转 / 真相翻转 |

### 十一种子标签（H1-H11）
| 标签 | 名称 | 触发条件 |
|---|---|---|
| H1 | 预示冲突 | 有人找主角对决/宣战 |
| H2 | 秘密 | 同伴藏信/锁盒/未拆包裹 |
| H3 | 重要决定/誓言 | 主角当众发誓/立约 |
| H4 | 宣布震惊事件 | 突然通报死亡/破产/背叛 |
| H5 | 激烈情绪 | 角色遭不公情绪爆发 |
| H6 | 颠覆性突转 | 已认定事实被推翻 |
| H7 | 新想法 | 主角想到对付反派的新方案 |
| H8 | 未回答的问题 | 留下待解的疑问对白 |
| H9 | 神秘对白 | 时间/地点暗号未解释 |
| H10 | 预言/异象 | 战场日食、诡异征兆 |
| H11 | 转折点 | 主角入孤儿院/流放/入狱 |

### 钩子相关动词
- **挂钩子** = 集末埋下下集必接的悬念
- **收钩子** = 下集开场承接前集集末画面
- **钩子塌方** = 钩子写得抽象/空话/无法可视化
- **钩子同质化** = 连续 3 集用同一子标签

## 二、节奏术语

### 分层（来自 [rhythm-control.md](../core/rhythm-control.md)）
| 术语 | 定义 |
|---|---|
| 分层 | 一段戏中"情绪/信息/事件"的切层节点 |
| 打断 | 当前层信息已介绍完，用意外因素推进下一层 |
| 节奏塌方 | 单场戏 3 分钟以上无分层 |
| 无效延长 | 事件结束后仍在同层反复消耗 |

### 反差对比
| 术语 | 定义 |
|---|---|
| 人物形象反差 | 霸总私下吃饭不修边幅 |
| 戏剧性反差 | 贫穷与富有 / 幸福与灾厄并置 |
| 身份反差 | 主角伪装废物 → 露出真实身份一缕 |

### 装 X
| 术语 | 定义 |
|---|---|
| 装 X | 主角隐藏身份/能力被打脸方反向打脸的高光时刻 |
| 装 X 密度 | 同一集内高光时刻的次数（不超过 2-3 次） |
| 装 X 阈值 | 重大高光之间必须跳天/铺垫/压制 |

### 围观
| 术语 | 定义 |
|---|---|
| 围观打脸 | 多人在场目击主角反向打脸（社死效应） |
| 围观者 | 见证打脸的群体（同事/朋友/路人） |
| 反向打脸 | 反派先嘲笑主角 → 主角揭真身 |

## 三、付费墙术语（来自 [paywall_formulas.md](paywall_formulas.md)）

| 术语 | 定义 |
|---|---|
| 首付墙 | 第 8-12 集首充转化点，is_paywall_a 标记 |
| 二付墙 | 第 26-28 集回流转化点，is_paywall_b 标记 |
| 强一倍原则 | 付费墙集次的钩子强度必须比其他集高一倍 |
| 未兑现期待 | 前几集积累的最强情绪期待，付费墙集集末被打断/反向 |
| 多重悬念 | 集末同时埋 ≥ 2 条独立悬念线 |
| 时间压力 | "必须在 X 时间内完成"的明确窗口 |
| 反转钥匙道具 | 二付墙集中暗示主角能反扑的关键物件 |

## 四、爆点 / 爽感术语

| 术语 | 定义 |
|---|---|
| 爆点 | 单集核心冲突落地的瞬间（揭露/打脸/反杀/告白） |
| 爆点模板 | 场所 + 动作 + 目标 + 类型 四要素组合（如"会议室+摔文件+揭露+围观打脸"） |
| 爆点重复 | 30 集内同一模板使用 ≥ 2 次 |
| 爽点即时 | 爆发→兑现的间隔不超过同一场戏 |
| 爽感分布 | 爆发点在前/中/末三段都有出现 |
| 三个起手 | 反派造势 + 主角隐忍 + 围观者就位（爆点的三段铺垫） |

## 五、状态卡术语（来自 [07_quality_check.md](../steps/07_quality_check.md)）

| 五轴 | 含义 |
|---|---|
| relationship | 关系：谁对谁立场/态度/距离的具体改变 |
| info_chain | 信息链：本集新揭露/新承接/新埋的信息线索（点状事实） |
| power_shift | 权力翻转：筹码消长/规则兑现的具体表现 |
| open_promise | 未完成承诺：集末留下的承诺，下集必须接 |
| no_change | 已锁定事实：禁改的确凿身份/已死/已查实 |

## 六、定格画面术语

| 术语 | 定义 |
|---|---|
| freeze_scene | 集末定格的具体场所（不能是"某处"） |
| freeze_characters | 在场角色（必须是已锁定的 canonical_name） |
| freeze_prop | 可视道具（账本/U盘/电话/项链/电报/信物） |
| freeze_action | 定格动作（"X 拿着 Y 站在 Z 前，话说一半"） |

**禁忌**：
- ❌ "决心要揭开真相"（内心戏）
- ❌ "某处一片黑暗"（抽象空镜）
- ❌ "某个不为人知的角落"（不具体）

## 七、硬否决码（来自评分系统）

| 编号 | 名称 | 定义 |
|---|---|---|
| ① | 重复 | 与前集 ≥ 80% 雷同的对话/情节段 |
| ② | 违锁 | 提前消耗后面集才该出现的关键事件/道具 |
| ③ | 死人复活 | 已死/已离场角色无铺垫复活 |
| ④ | 动机崩 | 主角与之前所有动机背道而驰，无理由 |
| ⑤ | 无推进 | 整集 = 上一集复读 |

## 八、人物术语

| 术语 | 定义 |
|---|---|
| canonical_name | 角色锁定的标准称呼（剧本中必须用此名，不能用代称） |
| 声纹卡 | 角色的口头禅、句式、语气样本（≥ 3 句） |
| 角色弧线 | 主角从开局到结局的内在状态变化轨迹 |
| 关系档位 | 试探 / 敌对 / 同盟 / 恋人 / 分裂 五档 |
| 工具人 | 没有独立动机、只为推进主角剧情存在的配角（贬义） |
| 软肋 | 角色致命弱点，反派可利用 |
| 人设崩 | 言行违背已建立的性格 |

## 九、节拍术语

| 术语 | 定义 |
|---|---|
| beat | 节拍，一段戏的最小冲突-动机-落点单位 |
| beat_sheet | 节拍表，全集 8-12 个里程碑事件的骨架 |
| season_milestones | 全季里程碑（每个让局面发生不可逆变化） |
| used_beats | 已用爆点池（防止重复） |
| open_promises | 未完成承诺池（下集必须接） |

---

## 十、字数与时长术语（漫剧/真人短剧通用）

| 术语 | 定义 |
|---|---|
| 净字 | 不含标点空白的有效汉字数 |
| 字秒比 | 10 字/秒（120 秒 = 1200 字） |
| 漫剧标准 | 90 秒 / 1000-1550 净字，中心目标约 1200 |
| 真人短剧标准 | 单集 2-3 分钟 / 1200-1500 净字 |
| 字数过载 | 明显高于项目上限 → 必须拆集或精简 |
| 字数不足 | 明显低于项目下限 → 必须加细节或场景 |

---

## 使用方式

- **所有 prompt 中**使用本词典的术语，确保 LLM 理解一致
- **Reviewer 评分时**使用本词典进行问题分类（如"节奏塌方"、"钩子同质化"）
- **新增术语**时需经评审，避免 LLM 在不同步骤中接收到术语漂移

**禁忌**：不要在 prompt 中重复词典中的定义全文，只引用术语名 + 文件路径，避免污染。
