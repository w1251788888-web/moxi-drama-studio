# 结构仿写方法论 v1.0
# 来源：新增知识图片（仿写铁律系列截图）
# 适用：改编项目（00_novel_analysis.md）、素材借鉴（所有步骤的 material_references 字段）
# 核心原则：仿写 = 保骨架，换血肉。100%保留钩子和结尾，只替换中间部分的观点/案例/比喻

---

## 核心原则

**仿写 ≠ 抄袭，仿写 = 保骨架，换血肉**

- 100% 保留：钩子、结尾、整体结构、字数、风格
- 只替换：中间部分的观点、案例、比喻

---

## 第一步：分析框架（拿到参考作品后必须先执行）

### #1 钩子识别
钩子不一定是第一句，根据以下特征判断边界：
- 制造好奇/悬念
- 创造冲突/反常识
- 直击痛点/引发共鸣
- 抛出利益点

**判断方法**：从头往后读，当内容从"吸引注意力"转向"展开论述"时，钩子结束。

### #2 结尾识别
结尾不一定是最后一句，根据以下特征判断：
- 情绪升华/金句收尾
- 行动号令
- 开放式问题
- 身份认同强化

**判断方法**：从结尾往前读，当内容从"收口/升华"转向"正文论述"时，结尾开始。

### #3 中间部分拆解
将钩子和结尾之间的内容按功能划分模块：
- 铺垫 / 论点 / 论据 / 类比 / 转折 / 升华
- 标记每个模块的：类型、字数、可替换元素

### #4 绑定关系识别
检查钩子中出现的元素是否在中间部分再次出现。
如果有绑定关系，中间部分的该元素也必须保留，不能替换。

### #5 风格提取
- 句式节奏（长短句比例）
- 人称视角（第一/第二/第三人称）
- 口语化程度（1-10分）
- 情绪浓度（克制/中性/激烈）
- 标点特征（感叹号频率/省略号使用）
- 总字数

## 第二步：仿写铁律

### 铁律一：结构层

| 规则 | 要求 |
|------|------|
| 钩子 100% 保留 | 只有新旧主题强相关时才能换关键词 |
| 结尾 100% 保留 | 经典金句、金句不动 |
| 绑定关系保留 | 钩子提到的元素在中间出现时不替换 |
| 字数完全对等 | 偏差 ≤ 3%，越接近越好 |
| 断句复刻 | 原文怎么结构，仿写什么结构 |
| 标点一致 | 句号对句号，逗号对逗号 |
| 断句节奏 | 短句对短句，长句对长句 |

### 铁律二：金句/观点层

| 规则 | 要求 |
|------|------|
| 情绪分量对等 | 不能降级也不能升级 |
| 表达烈度一致 | 原文温和原文极端，仿写同等烈度 |
| 比喻层对等 | 生死级换生死级，生活级换生活级 |

### 铁律三：证据/案例层

| 规则 | 要求 |
|------|------|
| 通俗易懂 | 用"普通人+异常"，不用专业名词 |
| 恐惧/冲击力对等 | 原文让人害怕多少，仿写同等冲击 |
| 权威来源对等 | 体检报告换体检报告，医生说换医生说 |
| 量感对等 | 原文具体，仿写也要具体，不能抽象 |
| 画面感清晰 | 每句都能清晰刻想到场景 |

### 铁律四：语感层

| 规则 | 要求 |
|------|------|
| 口语化程度一致 | "不信"不能写成"以为然" |
| 人称一致 | 原文用"我"就用"我"，无人称就无人称 |
| 情绪温度一致 | 恐惧还是恐惧，调侃还是调侃 |
| 音韵节奏顺畅 | 读起来像朋友在说话，有韵律感 |
| 前后句对仗感 | 前半句和后半句字数接近，有对称感 |

### 铁律五：禁止行为

- 不能降级：生死问题不能写成外观问题
- 不能升级：小事不能变成大事
- 不能抽象化：具体案例不能变成笼统道理
- 不能专业化：用普通人听不懂的术语
- 不能文字纠纷：口语文案不能写成书面语
- 不能破坏绑定关系：钩子提到的元素在中间出现时不替换
- 不能用不存在的典故：经典成语/名言不能自己编造

## 第三步：质量自检

仿写完成后，逐项检查：

| 检查项 | 方法 |
|--------|------|
| 字数节奏 | 前半句和后半句字数是否接近 |
| 音韵感 | 出声朗读一遍，是否朗朗上口 |
| 对仗感 | 前后句是否有对称感 |
| 画面感 | 每句是否能立刻刻想到场景 |

如有不通顺，必须调整至顺畅再输出。

| 场景 | 使用方式 |
|------|---------|
| 小说改编（00_novel_analysis.md） | 分析原著结构时，用分析框架提取可借鉴的钩子和结尾模式 |
| 概念规划（01_concept.md）| `material_borrow_focus` 字段中指定：借鉴开场结构 / 高潮节点位置 / 结尾情绪类型 |
| 剧本改稿 | 对已有初稿执行仿写四步法，对标参考爆款进行结构对齐 |
| 爆款段子/梗改编 | 用 #1-#5 分析框架拆解原梗，再按铁律替换内容 |
