## 核心原则

爽感 = 期待 × 兑现速度 × 围观人数 × 感官维度

- 期待越高，兑现越爽
- 兑现越快，节奏越紧
- 围观者越多，爽感传播性越强（可截图/可弹幕/可讨论）
- **感官维度越多，完播率越高**（数据：视觉+音效双触发完播率提升172%）

## 音效维度规则（v1.1 新增）
# 数据依据：耳光声+玻璃碎裂音效触发完播率提升172%（真人短剧平台实验数据）

**核心原则：爽感爆发点必须有设计感音效，不能只靠画面。**

### 音效触发清单（写入分镜提示词时必须标注）

| 爽感场景 | 推荐音效组合 | 禁忌 |
|---------|------------|------|
| 打脸/逆袭爆发 | 低沉撞击音 + 短促停顿（0.5秒静音）+ 震撼BGM起 | 不能直接起欢快BGM，停顿是爽感的"呼吸" |
| 身份揭露 | 金属刮擦/弦断音 + 周围人倒吸冷气声 | 不能用通用特效音，要有专属声纹 |
| 情感破防 | 音乐骤停 + 只留环境音（风/雨/心跳）| 不能在破防时用悲伤BGM，留白比填满更有力 |
| 系统/能力激活 | 机械合成音 + 数值滚动提示音 | 不能用魔法类音效，科技感>玄幻感更符合当前受众 |
| 宫斗/权谋亮牌 | 低沉弦乐渐强 + 脚步声节奏变化 | 节奏要配合角色阶级，主角脚步比配角沉稳 |
| AI仿真人奇观 | 前5秒只用环境音建立世界观，无人声 | 不能用熟悉的影视BGM，要建立专属世界声景 |

### 在剧本/分镜中的标注格式
```
【音效】耳光声+0.5秒静音+低频震动BGM起
【音效】机械合成音×3叠加+数值滚动提示音
```
漫剧项目：音效标注为必填项，写在对应动作行下方。
真人短剧：音效标注为建议项，但打脸/逆袭场必须标注。

## 银发受众轴（v1.1 新增）
# 数据依据："黄昏恋+打脸逆袭"对银发群体付费转化是甜宠剧的2.3倍

**定义**：45岁以上受众，主要分布在快手、微信视频号，付费意愿强但内容敏感度高。

### 银发受众专属爽感偏好

| 优先级 | 爽感类型 | 具体触发方式 | 转化倍数 |
|--------|---------|------------|---------|
| 第一 | S16（黄昏逆袭打脸） | 被子女/年轻人看不起 → 用几十年积累的能力/人脉/资源完成反转 | 2.3x |
| 第二 | S15（情感共鸣落泪） | 一段被忽视的付出被人看见，不需要大场面，一个细节就够 | 高留存 |
| 第三 | S7（反击得偿） | 隐忍多年的委屈在晚年得到宣泄，强调"来得及" | 高付费 |

### 银发受众写作禁忌
- 禁止：主角表现出明显的认知退化/记忆问题（回避老年痴呆相关剧情）
- 禁止：子女形象全员负面（快手平台尤其敏感，需有一个理解长辈的子女角色）
- 禁止：快节奏信息轰炸开场（银发用户需要2-3集建立信任感，蓄势段可以比年轻受众项目长）
- 推荐：情感浓度高于事件密度，更多"在一起的日常"而非"反转炸弹"

### 银发项目快速选择
```
银发 + 快手 → 优先 S16+S15+S7，题材：黄昏恋/家庭伦理/老年逆袭
银发 + 微信视频号 → 优先 S15+S8（老年版偏爱公开）+S16，题材：情感治愈/代际和解
```

## 爽感密度配置表（按情绪曲线段落）

### 蓄势段（约前15%集数）
目标：吊胃口，不要过早兑现
- 推荐类型：S12（身份埋雷）、S5（伤害被看见-轻版）、S9（漫剧反差初显）
- 密度：1个/集
- 要求：只露端倪，不要完全兑现；爽感强度控制在30%以内
- 银发项目：蓄势段可延长至前20%集数，用情感积累代替信息轰炸

### 爬升段（约30%集数）
目标：让观众养成追更习惯
- 推荐类型：S6（关系反转-小步）、S1（亮牌-小胜利）、S11（表情包时刻）
- 密度：2个/集
- 要求：每集至少有1次"小确爽"，兑现一个之前埋的小钩子

### 风暴段（约35%集数）★ 主要爽感区 + 双付费墙设计点
目标：最高密度爽感输出
- 推荐类型：全部类型均可，以 S2/S7/S9/S13 为核心
- 密度：3个/集，付费节点前后集4-5个/集
- **双付费墙节点**（以 `core-rules/long_series.md §二` 为唯一权威，位置随 episode_count 动态计算）：
  - 节点A（第一钩子墙）：约在全剧 30% 位置（= `round(episode_count × 0.3)` 集），设计"最强悬念未兑现"，引导首次付费
  - 节点B（充值高峰墙）：约在全剧 80% 位置（= `round(episode_count × 0.8)` 集），设计"全剧最大爽感即将爆发"，引导深度付费
  - 两个节点之间必须保持稳定的"小确爽"节奏，防止用户在中段流失

### 高潮段（约后20%集数）
目标：情感+爽感双爆发，收束全剧
- 推荐类型：S1+S7组合（亮牌+反击同时发生）、S2（最大围观打脸）、S13（最终反转）
- 密度：4+个/集
- 要求：每个爽感都是之前埋点的"总兑现"，不出现新埋点

## 爽感写法四步法

**Step 1 — 压制**：让主角在可见的压力下（不要纯心理，要有旁观者）
**Step 2 — 撑着**：主角忍住了，但观众感觉到"快撑不住了"
**Step 3 — 爆发**：触发爽感的那个动作/台词/事件，必须快、准、狠
**Step 3.5 — 音效落点**：爆发瞬间标注对应音效组合（参见音效触发清单）
**Step 4 — 余震**：爽感爆发后，让旁观者的反应持续1-2个场次（不要立刻进入下一个情节）

## 围观性设计指引

爽感没有围观 = 爽感强度 × 0.5

### 围观设计方式
1. **同场围观**：在爽感爆发现场安排3个以上旁观角色，给他们反应镜头
2. **传播围观**：爽感发生后，通过对话/截图/消息扩散让更多人"知道了"
3. **延迟围观**：主角做了什么，下一集有人讨论"你听说了吗"
4. **敌方视角**：反派/对手亲眼目睹，他们的慌乱/恐惧/嫉妒是最好的爽感放大器

### 漫剧特有围观形式
- 画面外的"弹幕式文字"（动作描述中注明）
- 夸张化集体反应（全场人同时做同一个动作）
- 第四堵墙式——角色像是在看向屏幕（隐约打破第四堵墙）
