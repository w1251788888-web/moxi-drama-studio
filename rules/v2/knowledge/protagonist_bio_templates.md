# 主角小传 Few-shot 模板（W3-A #4）

**用途**：02_characters 阶段生成主角设定卡时的对标模板。
**数据源**：拆解样本 + 知识库 A 类剧本主角抽取 + 104 集人评高分集主角设定。
**版本**：v1.0（2026-05-03）。

---

## 主角小传必备六要素

| 字段 | 说明 | 长度 |
|---|---|---|
| 表层身份 | 开场观众第一印象（被退婚的大小姐 / 落魄赘婿 / 重生的复仇者） | ≤ 20 字 |
| 深层身份 | 隐藏真实身份（神医 / 战神 / 隐世家族继承人） | ≤ 20 字 |
| 核心驱动 | 1 个最强动机（复仇 / 守护 / 翻身 / 报恩） | 1 句 |
| 金手指 | 能力来源 + 限制（重生 + 一周冷却 / 系统 + 任务奖励 / 医术 + 不能滥用） | 1 句 |
| 致命弱点 | 至少 1 个会被反派利用的软肋 | 1 句 |
| 声纹卡 | 说话风格（短句 / 反讽 / 冷嘲 / 内敛） | 2-3 句样本台词 |

**禁忌**：六要素任一缺失或写成空话（"勇敢、善良、聪明"）→ Reviewer 直接打回。

## 模板 1：男频战神（赘婿/兵王/绝世高手）

```yaml
canonical_name: 林尘 / 沈倦 / 江北
表层身份: 赘婿 / 落魄保安 / 倒插门女婿
深层身份: 龙隐战神 / 三界之主 / 全球军方共主
核心驱动: 守护妻女 + 隐忍报恩 + 让岳家由欺辱转为臣服
金手指: 顶级武力 + 全球势力网，一个电话调动百亿资源；限制 = 不主动暴露身份
致命弱点: 妻女在场时绝不还手（被反派当软肋反复利用）
声纹卡:
  - "嗯。"（多数情境的回应，最高频）
  - "够了。"（爆发前的临界点）
  - "我说了，让她走。"（保护妻女时的句式，必须冷且短）
开场异常: 妻女被欺辱→主角第一次微微起身→围观者还嘲笑→主角接电话直接调直升机
```

**人评高分剧本对应**：《龙王赘婿》《我都要无敌了你说我是赘婿》《战神归来》

## 模板 2：女频霸总甜宠（含契约/闪婚）

```yaml
canonical_name: 苏棠 / 顾倾澜 / 季凉川
表层身份: 被换嫁的二小姐 / 被退婚的高配老婆 / 离婚返场的前妻
深层身份: 跨国财阀真千金 / 神级设计师 / 隐世家族唯一继承人
核心驱动: 揭露姐姐/前夫家族的伪善 + 让前世受过的羞辱当面奉还
金手指: 重生记忆 + 隐藏家世；限制 = 不能直接说出未来
致命弱点: 对男主有未泯的爱（容易被男主"装弱"绕进去）
声纹卡:
  - "好。"（不解释，直接答应反派要求，让对方误判）
  - "你猜？"（反问式反击，最具攻击力的句式）
  - "苏柔，你刚刚说什么？"（点名重复，强迫反派当众重述）
开场异常: 抢婚现场→主角不哭不闹→冷静拿出反派造假账本副本→反派惊变
```

**人评高分剧本对应**：《十八岁太奶 3》《家里家外》《八零后妈》《说好利润五五分》

## 模板 3：女频重生复仇

```yaml
canonical_name: 沈微 / 顾梦笙
表层身份: 重生回到关键节点的旁观者
深层身份: 前世被害死/陷害的真千金/正室
核心驱动: 反向操作所有前世的死局 + 让反派步步走入她设的陷阱
金手指: 完整前世记忆 + 知晓未来 5-10 集走向；限制 = 蝴蝶效应不可控（每改一次未来生变）
致命弱点: 重生执念让她过于激进，容易被反派识破"重生者"身份
声纹卡:
  - "前世我以为……"（开场内心戏铺垫，每集 ≤ 1 次）
  - "这次轮到你了。"（标志性反向打脸句式）
  - "你已经晚了。"（反派出招时的截杀句）
开场异常: 第一集醒来 → 不是回到童年→是回到行刑前 30 秒→主角立刻反咬刽子手
```

**人评高分剧本对应**：《替妹出嫁》《重回 1982》《主角穿越史前部落》

## 模板 4：男频系统流

```yaml
canonical_name: 陈凡 / 林易
表层身份: 落魄/被退婚/被嘲笑的废柴
深层身份: 系统选定的天命之人
核心驱动: 完成系统任务 + 用奖励正面打脸所有看不起他的人
金手指: 系统签到/抽奖 + 任务奖励兑换；限制 = 任务必须接，违抗会反噬
致命弱点: 系统冷却期没奖励时是普通人（反派若发现冷却期会偷袭）
声纹卡:
  - "叮——签到成功。"（系统提示，每集 1-2 次）
  - "就这？"（拿到顶级奖励后的轻蔑）
  - "我再试试？"（解锁连续抽奖时的口头禅）
开场异常: 被前女友当众羞辱→系统提示完成"被绿任务"→直接奖励一栋豪宅
```

**人评高分剧本对应**：《大明1566，但我修仙》（系统化古风变体）

```yaml
开场异常: 重生第一天→不去找老朋友→直接打电话买下一片荒地→后被验证是即将拆迁的市中心
```

## 反派的对位设计（与主角配套）

每个赛道的反派必须**镜像主角**：
- 战神主角 → 反派是"假豪门 + 用钱压人 + 自以为是顶端"
- 重生女主 → 反派是"前世害她的姐妹 + 顶替了她的人生 + 即将翻车而不自知"
- 系统主角 → 反派是"靠家族资源 + 没有金手指但自以为开挂的人"

反派必备字段：
- 至少 1 次"看似合理但其实是阴谋"的微表情/动作（让观众早于主角发现）
- 至少 4 种失败方式（不允许 30 集都"愤怒离场"）
- 必须有 1 个让观众恨得牙痒痒的标志性恶习（拿手帕擦手 / 玩戒指 / 冷笑）

## 使用方式

1. **02_characters 阶段**：planner 按项目赛道挑模板，填入具体姓名、世界观背景
2. **声纹卡**：必须 ≥ 3 句样本台词，覆盖"日常 / 临界 / 爆发"三种状态
3. **禁忌**：本文模板的姓名、台词、身份组合**禁止照搬**，只学结构与思路
4. **Reviewer 校验**：六要素任一缺失 → 02_characters 步骤打回
