# 赛道节拍公式库（W3-A #1）

**用途**：concept / beat_sheet 阶段按项目赛道挑选对应骨架，作为里程碑设计的对标公式。
**数据源**：作者整理的剧本知识库与拆解样本 + 104 集人评归纳（第三方剧本文本未随本仓库分发）。
**版本**：v1.0（2026-05-03）。后续按真实生产数据回填修订。

---

## 通用节拍坐标系（30 集制）

| 集段 | 集号 | 核心任务 | 关键产出 |
|---|---|---|---|
| 抢入 | 1-3 | 钩住观众，建立反差/悬念/动机 | 主角"开场异常"+ 第一推力 |
| 蓄势 | 4-7 | 信息加密，关系拉紧，矛盾升级 | 第一次身份揭露 / 第一次代价 |
| **首付墙** | 8-12 | 全剧最强未兑现悬念 | `is_paywall_a: true` 标记集 |
| 爬升 | 13-18 | 反派资源减少 / 主角筹码增多 | 关系档位变化 / 反派阴谋暴露 |
| 风暴 | 19-25 | 高密度爆点 + 反转 | 关系翻转 / 危机时刻 |
| **二付墙** | 26-28 | 全剧最大爽感引爆前夜 | `is_paywall_b: true` 标记集 |
| 终局 | 29-30 | 最终对决 + 闭环 | 反派下场明确 / 伏笔全收 |

## 1. 女频 · 霸总甜宠（含契约/闪婚/虐恋）

**主原型**：#24 势力悬殊竞争 + #28 恋爱被阻碍
**辅原型**：#22 为情欲不顾一切

| 集段 | 节拍 |
|---|---|
| 1-3 | 抢婚/逃婚/被退婚 → 男主以"压制者+保护者"双面登场 → 第一次同框/同床 |
| 4-7 | 错位身世揭露（替身/失忆/伪装）→ 男主身份暴露/真相被反派威胁 |
| 8-12 | **首付墙**：男主性命/婚约面临极大威胁，女主必须做出"放弃自尊"的决定 |
| 13-18 | 关系升档（试探→暗中保护→联手对外）→ 反派联合外部势力反扑 |
| 19-25 | 误会爆发 → 男女主分离 → 女主独自承担反派攻击，男主回归救场 |
| 26-28 | **二付墙**：男主受伤/失踪/濒死，女主"血债血偿"全面复仇 |
| 29-30 | 男主回归 + 反派全员法办 + 婚礼/孩子/HE |

**钩子主类轮换**：H4 震惊宣布 → H6 颠覆突转 → H5 激烈情绪 → H11 转折点 → H8 未答问题（循环）
**禁忌**：连续 3 集无关系档位变化；男主 5 集内不出现强势保护动作。

## 2. 女频 · 重生复仇 / 替妹出嫁

**主原型**：#3 复仇 + #33 错误的判断
**辅原型**：#13 骨肉仇恨

| 集段 | 节拍 |
|---|---|
| 1-3 | 重生回到关键节点 → 第一次"反向操作"打脸反派 → 反派露出獠牙 |
| 4-7 | 揭露前世真相（反派身份/被陷害细节）→ 第一笔反向筹码到手 |
| 8-12 | **首付墙**：反派全面反扑，主角面临前世死局再现 |
| 13-18 | 收编盟友 / 离间反派阵营 / 财富翻盘 |
| 19-25 | 反派核心罪行被主角公开 → 法办/破产/众叛亲离 |
| 26-28 | **二付墙**：反派垂死反扑，主角"近乎赢"被一击翻盘 |
| 29-30 | 反派彻底覆灭 + 主角拥有前世失去的一切 |

**钩子主类轮换**：H6 颠覆突转 → H4 震惊宣布 → H7 新想法 → H11 转折点
**特征**：每集必有"前世此时彼时"对照，强化重生感；反派至少 4 次"愤怒离场"以外的失败方式。

## 3. 男频 · 战神/赘婿/逆袭

**主原型**：#3 复仇 + #24 势力悬殊竞争
**辅原型**：#30 野心、#27 发现所爱不荣誉

| 集段 | 节拍 |
|---|---|
| 1-3 | 主角扮猪 → 第一次小试身手露出獠牙 → 围观打脸 |
| 4-7 | 身份逐层揭露（连长→军神→战神/掌控全球）→ 反派加码挑衅 |
| 8-12 | **首付墙**：家人/兄弟受重伤，主角必须暴露顶级身份救人 |
| 13-18 | 各国势力来朝 / 老婆地位连升 / 反派阵营内乱 |
| 19-25 | 妻女被绑/老岳父被害 → 主角解封最强战力 |
| 26-28 | **二付墙**：主角"已死"消息传出，全球势力震荡 |
| 29-30 | 主角王者归来 + 反派全员肉体毁灭 + 接最强后续 |

**钩子主类轮换**：H1 预示冲突 → H3 重要决定 → H7 新想法 → H4 震惊宣布
**爽点节奏**：每集至少 1 次围观打脸；每 5 集 1 次身份升档。

## 4. 男频 · 系统流 / 签到

## 使用方式

1. **concept 阶段**：planner 选定 primary_archetype 后，从本文挑对应赛道节拍骨架
2. **02b_episode_outlines 阶段**：每集 main_event 必须落在赛道节拍的对应位置
3. **质检**：reviewer 检查里程碑是否覆盖赛道公式中的关键节点（首付墙/二付墙/终局闭环）

**禁止**：照搬本文台词或人物名；只学结构与节奏。
