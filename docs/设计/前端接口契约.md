# 前端 ↔ 后端接口契约（v2 · 生成/统计 新增）

> 所有接口：`POST /api/moxi/...`，`content-type: application/json`，统一信封
> `{ "ok": true, "value": ... }` / `{ "ok": false, "error": { code, message, details } }`
> 错误一律 HTTP 200（connection 路由限制），靠 `ok` 判断。

## 1. 项目与画布（已有）

| 接口 | 入参 | 出参 |
|---|---|---|
| `/hello` | `{}` | `{plugin,version,pid,cwd,projectsRoot,provider,model}` |
| `/projects/list` | `{}` | `ProjectSummary[]` |
| `/projects/create` | `{title, episodeCount, audience, genreMain, logline}` | `{project, canvas}` |
| `/project/get` | `{projectId}` | `{project, canvas, recovery}` |
| `/project/delete` | `{projectId}` | `{trashPath}` |
| `/canvas/rev` | `{projectId}` | `{rev, updatedAt}` |
| `/canvas/get` | `{projectId}` | `{canvas}` |
| `/canvas/apply` | `{projectId, ops[], baseRev?, idempotencyKey?}` | `{rev, results}` |
| `/node/content` | `{projectId, nodeId}` | `{text, version}` |
| `/node/save` | `{projectId, nodeId, text, baseVersion?}` | `{rev, results}` |
| `/check/run` | `{projectId, nodeId}` | `{findings, summary:{total,errors,warnings,verdict}, rev}` |
| `/export` | `{projectId, format: md\|txt\|docx, range?:{from,to}}` | `{format,path,bytes,sections,fallback}` |
| `/events/tail` | `{projectId, limit}` | `Event[]` |

**CanvasOp**：`node.create` / `node.update` / `node.transition` / `node.write` / `node.delete` / `edge.create` / `edge.delete` / `viewport.set`

**节点**：`{id,type,title,status,x,y,w,h,ref:{episode,scene},contentFile,contentVersion,meta,createdAt,updatedAt}`
类型 9 类：`project_root|settings|asset|beat_sheet|scene_list|script_scene|quality|compliance|delivery`
状态机：`draft→generating→review→{approved|rejected}`；`rejected→{draft|review}`；`approved→{blocked|draft}`；`blocked→{approved|draft}`

## 2. 生成任务（新增）

| 接口 | 入参 | 出参 |
|---|---|---|
| `/jobs/start` | `{projectId, from?, to?, provider?, model?, temperature?, skipConcept?}` | `Job` |
| `/jobs/list` | `{projectId?}` | `Job[]`（按创建时间倒序） |
| `/jobs/get` | `{jobId, projectId?}` | `Job`（运行中走内存；否则读 `history/jobs/<id>.json`，需 projectId） |
| `/jobs/cancel` | `{jobId}` | `Job` |
| `/jobs/resume` | `{projectId, jobId}` | `Job`（从第一个未完成集续跑） |

```ts
interface Job {
  id: string                   // job_xxx
  projectId: string
  projectTitle: string
  from: number; to: number
  status: 'queued' | 'running' | 'done' | 'done_with_errors' | 'cancelled' | 'failed'
  createdAt: string; startedAt: string|null; finishedAt: string|null
  provider: string; model: string; temperature: number
  progress: { total: number; done: number; failed: number; current: number|null }
  episodes: Array<{ ep:number; stage:'pending'|'beat'|'scene'|'script'|'check'|'compliance'|'done';
                    status:'pending'|'running'|'done'|'failed';
                    words:number; findings:number; error:string|null; updatedAt:string|null }>
  log: Array<{ ts:string; level:'info'|'warn'|'error'; msg:string }>
  usage: { calls:number; inputTokens:number; outputTokens:number }
  wordRange: { min:number; max:number }
}
```

错误码：`E_JOB_RUNNING`（同项目已有任务在跑）、`E_NOT_FOUND`、`E_BAD_REQUEST`、`E_CANCELLED`、`E_LLM`。

## 6. 客户端约束（务必遵守）

- 只允许 `POST`；不要再新增 fetch 路径（避免与 moxi-core 冲突）。
- 样式只用主题 token：`--dsw-alias-label-primary` / `--dsw-alias-label-secondary` / `--dsw-alias-bg-layer-1/2` / `--dsw-alias-border-l1` / `--dsw-alias-brand-primary`。
- 组件不要 `require('@deepseek-ai/dsh-client-ui-primitives')`。
- 构建：`node scripts/build-client.mjs moxi-canvas`（或 `moxi-admin`）；**不要重启 dsh 实例**（后台有 30 集生成任务在跑）。
