# 后台信息架构（S1.4 · moxi-admin 5 页）

> 依据：`ADR-001` §2.1；旧后台参考 `MoxiAdminView.vue`（2,908 行，含 SaaS 板块已删）；
> 视频参考「opus 管理系统模板」17 帧（视觉参考，不复制代码）。
> 原则：**5 页封顶**，单用户最小权限，所有写操作留审计。

---

## 0. 页面清单与优先级

| # | 页面 | 优先级 | 数据源（Host 路由） | 主要动作 |
|---|---|---|---|---|
| P1 | 工作台（KPI） | P0 | `/api/moxi/admin/overview` | 只读 + 快捷入口 |
| P2 | 项目 | P0 | `/api/moxi/admin/projects` | 打开/归档/删除（软删） |
| P3 | 规则与技能 | P1 | `/api/moxi/admin/rules` | 只读 + 重新扫描 + 校验 |
| P4 | 模型与用量 | P1 | `/api/moxi/admin/models` | 只读 + 探针触发 |
| P5 | 日志与导入导出 | P1 | `/api/moxi/admin/logs` | 只读 + 导出 + 导入 |

> 不做：账号/密钥/邀请码/套餐/支付/额度/多租户/成员权限 —— 全部随 SaaS 能力删除。
> 单机唯一的"权限"= DSH 本机会话与文件系统边界；后台不重建第二套鉴权。

## P1 工作台 KPI

- **布局**：4 个 KPI 卡（2×2）+ 1 条趋势折线 + 1 个"最近事件"列表。
- **KPI 口径**（对齐旧口径，去掉 SaaS 项）：
  | 卡 | 口径 |
  |---|---|
  | 项目数 | `projectsRoot` 下 `project.json` 计数（active / archived 分列） |
  | 节点数 | 所有项目 `canvas.json.nodes` 求和 |
  | 待审节点 | `status in (review, rejected)` 计数 |
  | 今日生成 | `events.jsonl` 中今日 `op=content.save` 且 `actor=agent` 的去重 nodeId 数 |
- **趋势折线**：近 14 天每日生成节点数（由 events 聚合）。
- **最近事件**：最近 20 条 events（时间 / actor / op / 项目 / 节点）。
- **空态**：无项目 → 引导"新建项目"（跳画布）。

## P2 项目

- **表格列**：名称 / 集数 / 节点数 / 已完成集数 / 状态 / 更新时间 / 操作。
- **操作**：打开（跳 `moxi-canvas` 该项目）/ 归档 / 删除（软删到 `.trash/`，二次确认）。
- **排序/筛选**：按更新时间倒序；状态筛选 active/archived；名称搜索（本地过滤）。
- **空态 / 错误态**：无项目 → 空态插画 + 新建；读取失败 → 错误条 + 重试，不清空已有列表（沿用旧前端"失败不清空"原则）。

## P3 规则与技能

- **两个分区**：
  1. **规则包**：`rules/v2/` 扫描结果——文件名 / 标题 / 字数 / 最后修改时间；点开右侧预览 Markdown。
  2. **技能**：`skills/moxi-drama-creation/` 的 `SKILL.md` 元数据（name/description/文件数/脚本数）。
- **动作**：重新扫描（`POST /api/moxi/admin/rules` 带 `action:'rescan'`）、规则体检（跑 `scripts/rule_lint.py`，显示 findings）。
- **不提供**：在线编辑规则（规则包走文件/git，避免后台变成第二个写入口）。

## P4 模型与用量

- **模型表**：provider / model / 是否启用 / contextWindow / maxTokens / 最近探针结果（来自模型链路探针输出）。
- **动作**：跑一次探针（`POST /api/moxi/admin/models` 带 `action:'probe'`，异步 job，前端轮询状态）。
- **用量**：会话数 / 工具调用数 / 按模型分组的调用次数（来自 DSH 会话日志聚合，若不可得则显示"未接入"——**不伪造数字**）。
- **明确不做**：额度、计费、成本折算（旧 SaaS 口径删除）。

## P5 日志与导入导出

- **日志**：跨项目 `events.jsonl` 聚合（时间 / 项目 / actor / op / 摘要），支持按项目、actor、op 过滤，游标分页。
- **导入**：从旧系统迁移（`scripts/migrate/` 的产物）或从 docx 导入剧本 → 生成项目 + 节点。**必须显示迁移校验结果（数量/字数/checksum 偏差）**。
- **导出**：单项目导出 docx/txt/md；显示产物路径与字节数。
- **危险动作**：全部二次确认；删除类走软删。

## 视觉与交互规范

| 项 | 规范 |
|---|---|
| 主题 | 亮/暗双主题，只用 `--dsw-alias-*` token；不写死颜色（除数据可视化色板） |
| 密度 | 行高 36px；卡片圆角 10px；字号 12/13/20 三档 |
| 空态/加载态/错误态 | 三态必须有；错误态带 code 与重试 |
| 危险动作 | 红色 + 二次确认 + 结果 toast |
| 长列表 | 游标分页（每页 50），不一次性拉全量 |
| 可访问性 | 按钮有 `aria-label`；表格有表头语义；焦点可见 |

## 与画布的边界

| 能力 | 归属 |
|---|---|
| 节点增删改、状态迁移、正文编辑 | **画布**（唯一写入口） |
| 项目级看板、跨项目统计、规则/模型总览、日志 | **后台**（只读为主） |
| 项目归档/删除 | 后台发起，但实际写操作仍走 `moxi-core` 服务 |
