## 二、产品上手（安装后怎么用）

### 2.1 安装

两种方式二选一（详见 [README](../README.md) 第 7 节）：

- **源码安装**：`git clone` 后执行 `bash dsh/profile/install.sh`，然后 `dsh --profile moxi`；
- **预编译包**：到 [Releases](https://github.com/w1251788888-web/moxi-drama-studio/releases/tag/v0.1.0-exp.5) 下载 zip / tar.gz，解压后按包内说明安装（默认 profile：`moxi-exp`）。

启动后终端会打印一个带 token 的地址（形如 `http://127.0.0.1:<port>/?token=...`），用浏览器打开它。

### 2.2 第一次使用（5 步）

1. 左侧栏 →「**墨戏画布**」→「**+ 新开一部剧**」：填剧名、集数、受众（男频/女频/混合）、题材、一句话故事；
2. 工具栏 →「**生成**」：选起止集（单任务上限 30 集，建议先跑 3 集试试）。进度抽屉实时显示每集阶段，可取消、失败可续跑；
3. 生成完成 → 工具栏「**可拍性**」：逐集看估算时长、场次、角色、集末钩子、是否在设定集内，然后**逐集签收**；
4. 点「**人工放行**」：未签收 / 签收失效 / 缺集末钩子会被拦下，弹窗给出具体集号；
5. 点「**导出**」：得到 docx（或 md / txt）。

> 也可以完全对话驱动：在 DSH 对话里直接说「新建一部 30 集女频甜宠，女主叫苏璃，一句话故事是……」，Agent 会调用 `moxi_*` 工具完成同样的操作。

### 2.3 可拍性签收与放行（核心机制）

- **可拍性报告**：逐集给出估算时长（±25% 容差）、场次、有对白角色、集末钩子、是否落在设定集内；
- **签收**：绑定当前稿件版本；签收后改稿，旧签收自动失效（stale），需要重新签收；支持撤回；
- **放行闸门**：未签收 / 签收失效 / 缺钩子 → 不放行；确需跳过必须填理由（≤300 字），理由写入审计；
- 闸门默认开启，可在 profile 的 `moxi-core` 配置里关闭（`releaseGateRequireSignoff` / `releaseGateRequireHook`）；
- 可拍性是**辅助判断**：时长是估算、钩子是文本特征检测，不能替代真人对白计时与场地/演员可行性判断。

### 2.4 导出

- 格式：`md` / `txt` / `docx`；`docx` 需要 Python 3 + `python-docx`，缺依赖时自动降级为 md 并写明原因；
- 后台「日志与导出」页可按项目 + 集范围导出；
- 导出完成弹窗：定位文件 / 下载副本 / 复制路径（定位仅限项目 `exports/` 目录内）。

### 2.5 管理后台

- **工作台**：KPI（项目数 / 节点数 / 已生成集数 / 总字数 / 待审 / 已批准 / 阻塞 / 草稿）；
- **项目**：项目表 + 打开画布 + 导出 + 删除；
- **规则与技能**：扫描 `rules/v2/` 的文件数、分类；
- **模型与用量**：当前模型、可选模型、链路探针、最近任务模型；
- **日志与导出**：审计日志、按范围导出、生成任务表。

### 2.6 数据在哪、怎么备份

- 默认位置：`~/Documents/Moxi/projects/`（每个项目一个目录：`project.json` / `canvas.json` / `content/` / `history/events.jsonl` / `versions/` / `exports/`）；
- 换目录：环境变量 `MOXI_PROJECTS_ROOT`，或在 profile 里给 `moxi-core` 配 `projectsRoot`；
- 备份：直接复制整个 `projects` 目录；
- 误删找回：删除是软删，项目在 `.trash/<projectId>.<时间戳>/`，搬回来即可；
- 卸载：`bash dsh/profile/install.sh --uninstall`（**不会删除项目数据**）。

### 2.7 常见问题

| 现象 | 处理 |
|---|---|
| 侧栏没有「墨戏画布」 | bundle 未挂载：`dsh --profile moxi --dump-config \| grep moxi`，重跑 `bash dsh/profile/install.sh` |
| 面板空白 / `slot entry crashed` | 客户端产物损坏：`node scripts/build-client.mjs` 后刷新页面 |
| 面板显示「项目列表读取失败」 | 项目根不可写：检查目录权限或 `MOXI_PROJECTS_ROOT` |
| 导出 docx 变成 md | 缺 `python-docx`：`pip install python-docx` |
| 端口被占用 | 换端口：`dsh --profile moxi --no-open --port 59912` |
| Windows 弹 `MOXI — cannot find` | 不要用 Win+R 输产品名；双击桌面「墨戏生花」快捷方式，或 `dsh --profile moxi-exp` |
| 其它问题 | 开 [Issue](https://github.com/w1251788888-web/moxi-drama-studio/issues/new)，附系统版本、`dsh --version`、复现步骤；Windows 可附 `moxi-diagnose.txt` |
