## 原则

**凡是可写正则或计数器判断的，一律不给模型。** 这不只是效率问题——见 `quality-gate.md` 的校准系数：模型在 `emotion`（r=0.09）、`density`（r=0.207）上与人评几乎不相关。能用脚本数的，就不要让模型猜。

检查分两类：

- **硬失败**：违反即拒收，不接受任何理由
- **告警**：记录并提示，不阻断

## 单集检查（提交前）

| 检查项 | 类型 | 说明 |
|---|---|---|
| 字数区间 | 硬失败/告警 | 见 `numeric-conflicts.md`：<1000 或 >1550 硬失败；1000-1150 或 1250-1550 告警；1150-1250 为目标。**口径：场景标头不计入**（剧本行业惯例，也是项目内既有核验采用的口径）；换行符不计入 |
| 场数上限 | 硬失败 | 见 `numeric-conflicts.md`：漫剧 **5-7 场**；真人 3-5 分钟 6-8 场；≤3 分钟 4-6 场 |
| 场景标头格式 | 硬失败 | 全篇统一，无说明稿/教程稿痕迹 |
| 角色名一致性 | 硬失败 | 必须与角色库 `canonical_name` 完全一致 |
| `cliffhanger_concrete` 四字段 | 硬失败 | 非空、非"无/未明/待续"、非抽象悬念 |
| `used_beats` ≥2 项 | 硬失败 | 每项含场景/动作/目标/类型四要素 |
| 钩子子标签合法性 | 硬失败 | 必须是 H1-H11 之一（见 `quality-gate.md` 唯一定义） |
| 禁词 | 硬失败 | 涉政、涉黄、明确品牌名、违禁药品、真实人名 |
| 上集 cliffhanger 承接 | 告警 | 本集开场是否以定格画面为起点 |
| **动线可拍性** | 告警 | 人物在同一时刻被安排了两个互斥的身体动作（边下楼边跳绳），或动作与场景空间矛盾。**本项此前完全缺失，已致事故** |
| 爽感密度 | 告警 | 见 `numeric-conflicts.md`：基础漫剧 ≥2 / 真人 3 分钟 ≥2、5 分钟 ≥3；付费墙前后 2 集需 4-5 个/集 |
| 情绪临界点计数 | 告警 | 脚本统计出现次数，辅助校验 `emotion` 分 |
| 新情节点密度 | 告警 | 每 200-300 字计数，辅助校验 `density` 分 |

## 跨集结构性检查（防"字段全绿但剧没了"）

> 这一整节是事故倒逼出来的。**它的存在理由**：一版集纲可以做到 11 个必填字段全填、钩子脚本全绿、单集合规全过，但**剧已经没了**——因为没有任何一项检查在问"这一集里，剧名的主语还在不在画面里"。
> 判例：《我的父母没素质》1-10 集，主角父亲连续 5 集零出场，`subgoal_for_protagonist` 填的是状态描述，反派成为叙事主体——而当时所有单集检查全过。

### 1. 命题主语在场率（硬失败）

**先定义命题主语**：从**剧名**与 **logline** 里提取，不是从主角表里提取。

- 《我的父母没素质》→ 命题主语是**陆时 + 苏芮**（不是苏念，更不是反派姜蔓）
- 判定方法：把剧名里的名词拿掉修饰语，看它指的是谁

**判定线**：

| 指标 | 阈值 | 类型 |
|---|---|---|
| 任一命题主语在场率 | **< 90% 打回** | 硬失败 |
| 同一命题主语连续零出场 | **≥ 3 集打回** | 硬失败 |
| 全部命题主语同场率 | 记录，不卡阈值 | 告警 |

**唯一豁免**：反派视点集，全剧 ≤ 2 集，且必须在字段里写明"主角线由哪条 B 线承担、B 线是否进正文"。

**配套写法（比检查更重要）**：反派要进画面，就让反派**走进主角的场景**，不许把主角从场景里挪走。判例里 ep8 改法——姜蔓进校捐图书角，同时把陆时苏芮按在最后一排，陆时还带了零食。

### 2. 主角主动动作跨集计数（硬失败）

对应 `known-issues.md` 冲突 4 的裁决（合规管不到累积性结构伤害）。

- 每集统计主角**主动发起**的动作数（不是被动作出的反应）
- **连续 3 集主动动作 = 0 → 打回**
- 主角为未成年人时，本项阈值收紧为**连续 1 集**（即每集必须 ≥1）

判定"主动"的可操作标准：句子里有主语是主角、且带一个及物动作动词（"她决定…""她说不…""她把…放进…"）。"她被问""她看着""她想弄明白"不算。

### 3. 主角目标是"目标"还是"状态描述"（告警 + 强制人工确认）

**这是最隐蔽的一项**：字段填了，所以看起来合规，但填的是状态。

| 反例（状态描述，判废） | 正例（目标） |
|---|---|
| 只想把黑板擦完 | 要在合影里保住爸妈的位置 |
| 想把话问明白 | 要问出那个阿姨为什么一直看她 |
| 希望有人来接她 | 要自己把签到表签完带回家 |

**可脚本化的初筛**：`subgoal_for_protagonist` 命中 `只想|只是|被|希望|想被|不知道该` 等被动标记，或不含任何动词 → 告警，转人工。

### 4. 叙事主体倒挂（告警）

统计每集 A 线正文里各人物的出现集数：

- 若**对手/反派的在场集数 > 命题主语的在场集数** → 告警"叙事主体倒挂"
- 若反派出现集数是连续的、命题主语是断续的 → 同上

**根因提示**：这是 `02b_episode_outlines.md` 要求 `subgoal_for_antagonist` 每集必填的结构性后果——反派是连续动作线、主角是状态线，镜头会自动倒向有动作的一方。**不是模型偷懒。**

### 5. 伏笔提前兑现（告警）

台账里记了 `expected_payoff_ep`，但只检查了"超期未回收"。**提前兑现同样有害**：

- 实际回收集号 < 预期集号 → 告警
- 提前 ≥ 5 集 → **硬失败**（判例里把 ep30 的身世牌提前到 ep9，早了 21 集）

### 6. 标称数字必须与实测一致（硬失败）

文档里出现的每一个量化声明——`正文（N 字）`、`M/10`、`连续 N 集`——**必须来自脚本实测，禁止估算**。

判例：同一份文档里，字数标称偏差最大 66 字；"双亲同场 4/10"实测为 2/10。**这两处都是估算，且估完没改标称。**

**执行方式**：写完后跑 `scripts/check_episode.py`，把实测值回填进文档，再重跑一次确认偏差为 0。

## 跨集漂移检查

借鉴 Story Systems 的 `bible:drift` 与 Page2Frame 的规范名映射。每集生成后跑一次，输出漂移报告。

**角色规范名映射**：维护 `canon/names.json`

```json
{
  "林若岚": ["林若兰", "林若岚 ", "若岚", "林小姐"],
  "沈临渊": ["沈临洲", "临渊", "沈总"]
}
```

生成前后各扫一遍：正文里出现的名字若不在映射表内 → 疑似新角色或改名漂移，告警。命中别名但非规范名 → 硬失败（这正是"林深→林森"漂移的根因）。

**事实一致性**：`locked_facts` 中已锁定的事实（已死、身份已查实、关系已确认）在后续集中若被违反 → 硬失败。这条直接对应 `hard_reject_codes` 的 ②违锁 与 ③死人复活，且是**纯确定性可查**的，不需要模型判断。

**状态卡连续性**：本集 `state_card_delta` 声明的变化，与上集声明的 `open_promise` 是否对得上。

## 伏笔台账

借鉴 jarvis-write 的 foreshadowing scheduler。维护 `canon/promises.jsonl`：

```json
{"id":"p003","planted_ep":4,"content":"账本造假","expected_payoff_ep":9,"status":"open"}
```

每集生成后：

- 新埋伏笔 → 追加记录
- 已回收 → 标记 `payoff_ep`
- **超过预期集号 3 集仍未回收 → 告警**（人评锚点里明确点名"伏笔过密导致后续解决困难"是典型低分特征）
- **早于预期集号回收 → 告警；提前 ≥5 集 → 硬失败**（见上文跨集结构性检查第 5 项）

这条能与 `seed_payoff` 维度形成交叉验证：模型打分说伏笔处理好，但台账显示 5 条伏笔积压未回收，则模型分不可信。

**需连带依赖一起复制（4 个）**：

## 随 Skill 提供的脚本

`scripts/check_episode.py`——纯标准库，零依赖，只做能计数的事。

```bash
# 集纲（默认字数区间 150-250）
python3 scripts/check_episode.py --file "/abs/1-10集细纲.md" \
    --protagonists "陆时,苏芮" --antagonist "姜蔓" --exempt-eps 5

# 剧本（字数区间换成项目口径）
python3 scripts/check_episode.py --file "/abs/第01集.md" \
    --body-pattern '正文（(\d+) 字）' --words-min 950 --words-max 1000 \
    --protagonists "陆时,苏芮"
```

**已实现 6 组检查**，对应本文件上面的各项：

| 脚本输出 | 对应检查项 | 类型 |
|---|---|---|
| 【1】正文字数区间 **+ 标称与实测一致** + 场数 | 字数区间、场数上限、标称实测 | 硬失败 |
| 【2】钩子合法性与 5 集滑窗 | 钩子子标签、多样性窗口 | 硬失败 |
| 【3】命题主语在场率、连续零出场 | 跨集第 1 项 | 硬失败 |
| 【4】反派在场集数 > 命题主语 | 跨集第 4 项 | 告警 |
| 【5】`subgoal` 命中被动标记 | 跨集第 3 项 | 告警 |
| 【6】集标题去重 | — | 硬失败 |

**尚未实现**（需语义，留给模型或人工）：动线可拍性、主角主动动作计数、伏笔提前兑现、情绪临界点。

**两种模式**：

| 模式 | 触发 | 说明 |
|---|---|---|
| 多集细纲 | 默认 | 按 `--ep-pattern`（默认 `### 第 N 集《标题》`）切集 |
| 单集剧本 | 加 `--single` | 一个文件 = 一集；正文取 `--body-section` 标题下的内容 |

**关键参数**：

| 参数 | 说明 |
|---|---|
| `--protagonists` | **命题主语**，从剧名和 logline 里提，不是从主角表里抄 |
| `--exempt-eps` | 只给反派视点集用，全剧 ≤2 集；**豁免不影响"连续零出场"的计数** |
| `--ep-pattern` | 集标题正则。`第 01 集` 这种补零写法要用 `第 0?(\d+) 集《([^》]+)》` |
| `--scene-header` | 场景标头正则，默认 `\*\*【`；用于场数统计与字数剔除 |
| `--count-headers` | 场景标头计入字数（默认不计） |
| `--scenes-min/--scenes-max` | 场数区间；0 = 不检查 |

**用法要点**：

- 退出码 1 = 有硬失败；告警打印但不阻断
- **跑完要把实测值回填进文档，再重跑一次确认偏差为 0**
- 剧本字数区间示例：`--words-min 950 --words-max 1000 --scenes-min 4 --scenes-max 6`（真人 ≤3 分钟）
